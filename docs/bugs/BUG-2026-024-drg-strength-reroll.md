# BUG-2026-024 — DRG-4U потерял переброс проверки силы

## Суть

После ограничения бесплатных перебросов в PR #32 экипированный DRG-4U
не предоставляет разрешённый картой переброс всех кубиков проверки силы.

## Среда

- Версия приложения / commit: PR #32, `6b260d3`.
- Платформа и версия ОС / браузера: ошибка общего движка правил.
- Устройство или размер окна, если важно: не влияет на расчёт.
- Режим игры / состав партии / seed, если важно: локальная полная партия,
  учёный и охранник, seed 42; для UI — 1280×800.

## Подготовка и шаги воспроизведения

1. Экипировать робота `drg-4u` из поддерживаемого каталога особых предметов.
2. Начать проверку силы.
3. Проверить число доступных перебросов и источник в окне решения.

Частота воспроизведения: всегда на указанном commit.

## Результат

- **Фактический:** `skillRerollSources` принимает только
  `dice.reroll.allForSkill`; у DRG-4U указан `dice.reroll.all`.
  Проверка силы получает ноль перебросов.
- **Ожидаемый:** экипированный DRG-4U даёт один переброс всех кубиков
  проверки силы и указывается как источник в UI. Другие навыки и робот
  в рюкзаке этого права не дают; после использования лимит исчерпывается.
- **Основание ожидания:** `content/special_items.json`,
  `content/i18n/ru.json` (`content.item.drg-4u.description`),
  [словарь эффектов](../effects-vocabulary.md).
  [Спецификация правил](../rules-spec.md), «Зафиксированные цифровые решения
  для событий»: усталость роботов в текущей модели отсутствует.

## Влияние

- Что пользователь не может сделать или какое состояние портится:
  нельзя использовать способность предмета, меняется вероятность успеха.
- Масштаб / обходной путь: проверки силы с экипированным DRG-4U;
  корректного обходного пути в игре нет.
