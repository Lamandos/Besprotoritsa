# BUG-2026-072 — Перемещение GHB-DTN не засчитывает прибытие для квеста

## Суть

Перемещение героя роботом GHB-DTN не отправляет событие прибытия в целевой отсек
активному сюжетному заданию.

## Среда

- Версия приложения / commit: PR #33, commit `9230766`.
- Платформа и версия ОС / браузера: rules-пакет, все платформы.
- Устройство или размер окна, если важно: не важно.
- Режим игры / состав партии / seed, если важно: активное задание с условием `arrive`; GHB-DTN переносит героя в нужный открытый отсек.

## Подготовка и шаги воспроизведения

1. Активировать сюжетное задание с условием прибытия в отсек.
2. Экипировать готовый GHB-DTN и открыть доступный путь к целевому отсеку.
3. Переместить героя GHB-DTN в целевой отсек.
4. Проверить прогресс условия прибытия.

Частота воспроизведения: всегда.

## Результат

- **Фактический:** герой перемещается, но прогресс условия прибытия не меняется.
- **Ожидаемый:** вход в целевой отсек засчитывает условие `arrive`.
- **Основание ожидания:** `docs/rules-spec.md` (раздел «Сюжетная кампания», условие `arrive` при входе в отсек) и текст карты в `content/i18n/ru.json`.

## Влияние

- Игрок может не завершить сюжетную цель даже после входа в требуемый отсек.
- Масштаб / обходной путь: использовать обычное перемещение, если оно доступно.

## Доказательства

Замечание последнего ревью PR #33: `discussion_r4237678268`.
