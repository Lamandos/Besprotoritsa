# BUG-2026-120 — В результате события показывается успех без проверки

## Суть

События без проверки навыка показывают «Успех» в окне результата, хотя у карты нет развилки успеха и провала.

## Среда

- Версия приложения / commit: локальная рабочая копия; commit не зафиксирован в отчёте.
- Платформа и версия ОС / браузера: неизвестно.
- Устройство или размер окна, если важно: неизвестно.
- Режим игры / состав партии / seed, если важно: неизвестно.

## Подготовка и шаги воспроизведения

1. На карте «Вторжение: Медицинский отсек» или при обыске трупа выбрать доступный вариант и посмотреть результат.

Частота воспроизведения: по сообщению пользователя; точная частота неизвестна.

## Результат

- **Фактический:** В окне появляется строка «Успех».
- **Ожидаемый:** Показывать «Успех» или «Провал» только когда для варианта действительно проводилась проверка с таким исходом; для автоматического выбора без проверки показывать только фактические последствия.
- **Основание ожидания:** Явное требование пользователя; docs/rules-spec.md, § «Фаза событий» описывает показывать фактический исход успеха или провала после проверки.

## Влияние

- Что пользователь не может сделать или какое состояние портится: Игрок получает неверный сигнал, будто проходила проверка.
- Масштаб / обходной путь: сценарии, описанные выше; обходной путь неизвестен.
