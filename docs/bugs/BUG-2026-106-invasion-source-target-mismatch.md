# BUG-2026-106 — Транскрипции вторжений указывают чужие сектора

## Суть

В исходной транскрипции событий 13–24 заголовки вторжения сдвинуты относительно
ID события. В результате литературный текст называет сектор, который не совпадает
с названием и фактической целью соответствующего события.

## Среда

- Версия приложения / commit: PR #35, commit `0dd6d30d80f8a6c4ac27c9293f92c65f96a93ce5`.
- Платформа и версия ОС / браузера: веб-версия; точные версии неизвестны.
- Устройство или размер окна, если важно: не важно.
- Режим игры / состав партии / seed, если важно: просмотр результата события вторжения с ID 13–24.

## Подготовка и шаги воспроизведения

1. Разыграть любое событие вторжения с номером 13–24.
2. Сверить сектор в заголовке транскрипции с сектором из ID и названием события.

Частота воспроизведения: всегда для затронутых карт.

## Результат

- **Фактический:** например, `invasion-escape-pods-13` показывает заголовок
  «ВТОРЖЕНИЕ: Главный компьютер», хотя ID и игровое событие относятся к
  спасательным капсулам. Остальные затронутые заголовки аналогично сдвинуты.
- **Ожидаемый:** каждый заголовок транскрипции называет тот же сектор, что ID и
  название/цель события.
- **Основание ожидания:** `content/events.json`, `content/i18n/ru.json` и замечание
  ревью PR #35: <https://github.com/Lamandos/Besprotoritsa/pull/35#discussion_r4274004615>.

## Влияние

- Что пользователь не может сделать или какое состояние портится: игрок получает
  противоречивую инструкцию, куда размещать монстра.
- Масштаб / обходной путь: затронуты события вторжения 13–24; правильная цель
  события в игровом состоянии не меняется.

## Доказательства

Замечание P1 в ревью PR #35 указывает пример `invasion-escape-pods-13` и
сдвинутые последующие записи.

## Границы проверки

- Подозреваемая область кода (если известна): `content/event_source_text_ru.json`

  `packages/besprotoritsa_app/test/reported_gameplay_bugs_test.dart`.
- Релевантные существующие тесты / спецификации: регрессионные проверки BUG-2026-101.
- Что пока неизвестно: ничего; названия секторов однозначно заданы ID и
