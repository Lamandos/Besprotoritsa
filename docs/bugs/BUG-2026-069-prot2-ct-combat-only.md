# BUG-2026-069 — PROT2-CT активируется вне боя

## Суть

Валидация разрешает готовый экипированный PROT2-CT даже когда в секторе героя нет
монстра. Это позволяет заранее включить защиту от монстров, которые придут позже.

## Среда

- Версия приложения / commit: PR #33, commit `b0a1071`.
- Платформа и версия ОС / браузера: rules-пакет, все платформы.
- Устройство или размер окна, если важно: не важно.
- Режим игры / состав партии / seed, если важно: активный герой с экипированным готовым PROT2-CT; в его секторе нет монстров.

## Подготовка и шаги воспроизведения

1. Экипировать и не истощать PROT2-CT.
2. Находясь в секторе без монстров, применить его способность.
3. Проверить бонус защиты на текущий раунд и состояние готовности робота.

Частота воспроизведения: всегда.

## Результат

- **Фактический:** робот активируется вне боя, поворачивается и записывает бонус защиты на раунд.
- **Ожидаемый:** PROT2-CT можно активировать только при наличии монстра в секторе героя; вне боя команда отклоняется и робот остаётся готовым.
- **Основание ожидания:** текст карты ограничивает применение боем (указано в замечании `discussion_r4237583949`); `docs/rules-spec.md`, раздел «Роботы», задаёт поворот робота при использовании. Спецификация не содержит отдельного правила, позволяющего обходить условие карты.

## Влияние

- Игрок может заранее получить защиту против монстров, прибывающих после активации, и применить её без боя.
- Масштаб / обходной путь: активировать PROT2-CT в безопасном секторе перед фазой монстров.
