# BUG-2026-011 — Выбор цели по координатам не показывает актуальную карту

## Суть

В эффектах и решениях, где нужно выбрать поле для размещения врага или
перемещения персонажа, игроку предлагается выбрать координаты поля без наглядной
проекции карты. По запросу владельца проекта, при таком выборе нужно показывать
карту в её текущем состоянии с расположением персонажей и врагов.

## Среда

- Версия приложения / commit: неизвестно
- Платформа и версия ОС / браузера: неизвестно
- Устройство или размер окна, если важно: игровой экран; размер неизвестен
- Режим игры / состав партии / seed, если важно: эффект или решение с выбором
  поля назначения

## Подготовка и шаги воспроизведения

1. Запустить игру и открыть карту, на которой есть персонажи и/или враги.
2. Дойти до карты события или другого решения, которое просит выбрать поле для
   размещения врага либо перемещения персонажа.
3. На карте события, требующей выбора места появления монстра, открыть окно
   вариантов размещения.

Частота воспроизведения: неизвестно.

## Результат

- **Фактический:** цель выбирается по списку координат; проекция карты с её
  текущим состоянием и фигурами не показана.
- **Ожидаемый:** при выборе поля показывается актуальная проекция карты, на
  которой видны персонажи и враги, а игрок выбирает целевое поле на этой карте.
- **Основание ожидания:** требование пользователя от 2026-10-06.

## Влияние

- Что пользователь не может сделать или какое состояние портится: уверенно
  соотнести предложенные координаты с расположением на карте и выбрать нужное
  поле.
- Масштаб / обходной путь: относится к выборам поля назначения; конкретные
  эффекты и обходной путь неизвестны.

## Доказательства

Скриншот или запись экрана не предоставлены.

## Границы проверки

- Подозреваемая область кода (если известна): интерфейс решений игрового экрана
  и выбор поля; конкретный файл неизвестен.
- Релевантные существующие тесты / спецификации: `docs/rules-spec.md`,
  `docs/mvp_spec.md` и тесты выбора цели требуют проверки для затронутых карт.
- Что пока неизвестно: требуется ли оставлять координатные кнопки как альтернативу нажатию по карте.
- Уточнение владельца от 2026-10-06: для всех событий с выбором места появления монстра цель сейчас выбирается в модальном окне с кнопками, подписанными координатами; в самом окне нужна проекция текущей карты с персонажами и врагами, чтобы выбирать поле на карте.

## Регрессионный тест

- Тестовый файл и имя теста: `packages/besprotoritsa_app/test/mvp_screen_test.dart`, `monster placement decision shows a board projection`
- Команда запуска: `cd packages/besprotoritsa_app && flutter test test/mvp_screen_test.dart --plain-name 'monster placement decision shows a board projection'`
- **До исправления (красный):** `flutter test test/mvp_screen_test.dart --plain-name 'monster placement decision shows a board projection'` из `packages/besprotoritsa_app`.
- Результат и причина падения: assertion не нашёл `event-target-board-map`; окно размещения показывало варианты без проекции карты внутри.
- **После исправления (зелёный):** та же команда — тест прошёл; касание подсвеченной клетки разместило монстра, окно выбора закрылось.
- Результат связанных проверок: `flutter test test/mvp_screen_test.dart` — 3 теста прошли.

## Исправление

- Изменённые файлы: `packages/besprotoritsa_app/lib/src/mvp/mvp_game_screen_part_2.dart`, `mvp_game_screen_part_3.dart`, `mvp_game_screen_part_5.dart`, `test/mvp_screen_test.dart`.
- Краткое описание исправления: окна с выбором координат показывают проекцию доски с жетонами; координаты-поля отображаются подсвеченными, а нажатие по ним выбирает соответствующий вариант.
- Остаточные ограничения или связанные баги: не определены
