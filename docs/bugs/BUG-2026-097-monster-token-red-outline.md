# BUG-2026-097 — Жетоны монстров недостаточно выделяются на поле

## Суть

Жетоны монстров на поле плохо отделяются от фона. Им нужен красный контур.

## Среда

- Версия приложения / commit: текущая локальная `main`, commit `e843dac7`.
- Платформа и версия ОС / браузера: Flutter UI, платформы не ограничены.
- Устройство или размер окна, если важно: не важно.
- Режим игры / состав партии / seed, если важно: монстр отображается на поле.

## Подготовка и шаги воспроизведения

1. Создать монстра на поле.
2. Осмотреть жетон на фоне тайла и соседних жетонов.

Частота воспроизведения: всегда.

## Результат

- **Фактический:** жетон не имеет красного контура.
- **Ожидаемый:** у видимого жетона монстра есть различимый красный контур.
- **Основание ожидания:** требование владельца продукта в сообщении от 2026-10-11.

## Влияние

- Монстров труднее заметить на поле.
- Масштаб / обходной путь: все игровые поля.

## Доказательства

Сообщение владельца продукта в текущем диалоге.

## Границы проверки

- Подозреваемая область кода: `_MonsterToken` в `packages/besprotoritsa_app/lib/src/mvp/mvp_game_screen_part_3.dart`.
- Релевантные существующие тесты / спецификации: `packages/besprotoritsa_app/test/mvp_screen_test.dart`.
- Что пока неизвестно: нет.

## Регрессионный тест

- Тестовый файл и имя теста: `packages/besprotoritsa_app/test/reported_gameplay_bugs_test.dart` — `BUG097 monster tokens have a red outline`.
- Команда запуска: `cd packages/besprotoritsa_app && flutter test test/reported_gameplay_bugs_test.dart --plain-name 'BUG097 monster tokens have a red outline'`.
- **До исправления (красный):** тест завершился assertion failure: ожидаемый `monster-token-outline-outlined-monster` отсутствует.
- Результат и причина падения: жетон монстра сейчас не получает отдельную красную рамку.
- **После исправления (зелёный):** целевой тест и полный `flutter test test/reported_gameplay_bugs_test.dart` прошли; полный тестовый файл завершился `00:04 +44: All tests passed!`.
- Результат связанных проверок: widget assertion подтвердил рамку `#E53935` у жетона.

## Исправление

- Изменённые файлы: `packages/besprotoritsa_app/lib/src/mvp/mvp_game_screen_part_3.dart`, `packages/besprotoritsa_app/test/reported_gameplay_bugs_test.dart`.
- Краткое описание исправления: жетоны монстров обведены красной рамкой; она применяется и к открытому арту монстра, и к черепу скрытой угрозы.
