# BUG-2026-094 — Монстр из события раскрывается при размещении в закрытом секторе

## Суть

При событии, предписывающем при закрытой целевой локации выбрать любой закрытый
сектор, монстр может появиться открыто в секторе героя; сведения о его виде также
попадают в результат события. Карта должна оставаться неизвестной до открытия
сектора.

## Среда

- Версия приложения / commit: текущая локальная `main`, commit `e843dac7`.
- Платформа и версия ОС / браузера: rules и Flutter UI, платформы не ограничены.
- Устройство или размер окна, если важно: не важно.
- Режим игры / состав партии / seed, если важно: событие `invasion-*`, целевая локация закрыта, на поле есть открытый сектор героя и несколько закрытых секторов.

## Подготовка и шаги воспроизведения

1. Оставить закрытой локацию, указанную картой вторжения.
2. Разыграть карту, требующую поместить монстра лицом вниз в любой закрытый сектор.
3. Проверить выбор клетки, фактическое размещение и текст результата события.
4. Осмотреть закрытый сектор до и после его открытия.

Частота воспроизведения: неизвестно; подтверждено сообщением владельца продукта.

## Результат

- **Фактический:** выбор сектора не был доступен; монстр появился открыто в открытом секторе героя, а результат раскрыл его вид.
- **Ожидаемый:** при закрытой целевой локации игрок выбирает любой допустимый закрытый сектор; до открытия клетки на поле виден только значок черепа, а журнал/результат не раскрывает монстра. После открытия клетки показываются его карта и характеристики.
- **Основание ожидания:** текст вторжений в `content/i18n/ru.json` предписывает разместить монстра в закрытом секторе «в закрытую»; `docs/rules-spec.md`, раздел «Фаза монстров», указывает, что монстр, появившийся в закрытой клетке, остаётся там до её открытия.

## Влияние

- Неверное место появления может начать бой в другом секторе; закрытая карта раскрывает игрокам информацию, которую они должны узнать при открытии сектора.
- Масштаб / обходной путь: вторжения с закрытой указанной локацией и другие эффекты, размещающие монстров в закрытых клетках.

## Доказательства

Сообщение владельца продукта в текущем диалоге; типичная карта: `invasion-escape-pods-1`.
Дополнительное уточнение со скриншотом: «Упырь» виден в секторе героя, но карточка
показывает только «Сила боя: 3» и отключённую кнопку атаки. Это тот же неверный
открытый спавн: монстр должен быть выбран в закрытом секторе и оставаться черепом,
поэтому его карточку нельзя открыть до исследования сектора.

- Что пока неизвестно: точный id разыгранной карты не указан; проверка начнётся с семейства `invasion-*` с `fallback: closedSector`.

- Команды запуска: `cd packages/besprotoritsa_app && flutter test test/reported_gameplay_bugs_test.dart --plain-name 'BUG094 closed-sector event monster stays unknown'`; `cd packages/besprotoritsa_app && flutter test test/reported_gameplay_bugs_test.dart --plain-name 'BUG094 monster in a closed sector uses an unknown skull token'`; `cd packages/besprotoritsa_rules && dart test test/game_state_test.dart --name 'projectFor exposes a generic marker for a hidden monster' --reporter expanded`.
- **До исправления (красный):** тест результата нашёл `Появился монстр: Волколак` вместо скрытого имени; UI-тест не нашёл `☠`; rules-тест получил пустой список монстров вместо обезличенного маркера.
- Результат и причина падения: событие раскрывает имя монстра, закрытый жетон отсутствует, а multiplayer-проекция скрывает маркер полностью.
- **После исправления (зелёный):** `flutter test test/reported_gameplay_bugs_test.dart` завершился `00:04 +44: All tests passed!`; `dart test test/game_state_test.dart --reporter expanded` — `All tests passed!`; `dart test test/mvp_round_loop_test.dart --reporter expanded` — `All tests passed!`.
- Результат связанных проверок: тест точного события `invasion-escape-pods-1` прошёл всю цепочку: выбор доступен и содержит только закрытые сектора; после размещения результат не показывает имя; тесты проекции и прежних вариантов вторжения прошли.

## Исправление

- Изменённые файлы: `packages/besprotoritsa_rules/lib/src/game_state_part_2.dart`, `packages/besprotoritsa_rules/lib/src/game_state_part_6.dart`, `packages/besprotoritsa_rules/lib/src/commands_reducer_part_7.dart`, `packages/besprotoritsa_app/lib/src/mvp/mvp_game_screen_part_3.dart`, `packages/besprotoritsa_app/lib/src/mvp/mvp_game_feedback.dart`, соответствующие тесты.
- Краткое описание исправления: в закрытых секторах показывается обезличенный маркер с черепом; журнал события не содержит id монстра, а результат использует текст «неизвестная угроза». Игрокская проекция передаёт только маркер и координату без карты, статов и снаряжения. Первоначальное отсутствие выбора сектора на актуальной ветке не воспроизвелось: точный игровой сценарий предлагает выбор закрытых секторов.
- Остаточные ограничения или связанные баги: нет.
