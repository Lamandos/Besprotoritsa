# BUG-2026-145 — Подсказка о выборе показывается для единственного варианта события

## Суть

Окно события выводит «Выберите вариант события», даже если у события ровно один доступный вариант.

## Среда

- Версия приложения / commit: `main`, commit `96de380`.
- Платформа и версия ОС / браузера: неизвестно.
- Устройство или размер окна, если важно: неизвестно.
- Режим игры / состав партии / seed, если важно: окно события с одним вариантом.

## Подготовка и шаги воспроизведения

1. Дождаться события, у которого один вариант.
2. Посмотреть над кнопкой единственного варианта.

Частота воспроизведения: всегда при событии с одним вариантом.

## Результат

- **Фактический:** Над вариантом показана подсказка «Выберите вариант события».
- **Ожидаемый:** Не показывать эту подсказку, если вариант один.
- **Основание ожидания:** Явное требование пользователя; скриншот `2.jpg`.

## Влияние

- Что пользователь не может сделать или какое состояние портится: интерфейс занимает место повторяющей подсказкой и создаёт впечатление выбора.
- Масштаб / обходной путь: низкое влияние.
