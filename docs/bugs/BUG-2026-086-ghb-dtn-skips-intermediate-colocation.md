# BUG-2026-086 — GHB-DTN пропускает встречи на промежуточном секторе

## Суть

При перемещении героя GHB-DTN сразу меняет координату на конечный сектор и проверяет столкновения только там. Монстр или Нарыв на промежуточном шаге не срабатывает.

## Среда

- Версия приложения / commit: PR #33, `011f900`.
- Платформа и версия ОС / браузера: rules-пакет, все платформы.
- Устройство или размер окна, если важно: не важно.
- Режим игры / состав партии / seed, если важно: активный GHB-DTN, открытый путь длиной 2 шага, угроза на промежуточном секторе.

## Подготовка и шаги воспроизведения

1. Экипировать готовый GHB-DTN; открыть путь из стартового сектора через коридор к соседнему отсеку.
2. Поставить монстра с атакой на промежуточный коридор.
3. Переместить героя GHB-DTN в отсек за коридором.

Частота воспроизведения: всегда.

## Результат

- **Фактический:** герой телепортируется в конечный отсек; встреча с монстром в коридоре не разрешается.
- **Ожидаемый:** путь проходится по шагам; после входа в промежуточный сектор разрешается колокация, включая атаку монстра и окно уклонения.
- **Основание ожидания:** `docs/rules-spec.md`, раздел «resolveColocation и Нарыв»: колокация обязательна после каждого очка движения игрока, в том числе при принудительном перемещении. Описание GHB-DTN в `content/effects_inventory.json` разрешает переместить героя на два сектора. Замечание ревью PR #33, comment `4239301694`.

## Влияние

- Что пользователь не может сделать или какое состояние портится: принудительное перемещение позволяет обходить атаки монстров и взрывы Нарывов на пересечённых секторах.
- Масштаб / обходной путь: использование GHB-DTN на пути с угрозой в промежуточном секторе.

## Доказательства

Замечание последнего ревью PR #33, comment ID `4239301694`.
