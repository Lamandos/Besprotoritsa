# BUG-2026-108 — После переброса остаётся первоначальное значение кубика

## Суть

После переброса результат броска отображается так же, как до переброса.

## Среда

- Версия приложения / commit: неизвестно; рабочая копия `59874b7`.
- Платформа и версия ОС / браузера: неизвестно.
- Устройство или размер окна, если важно: неизвестно.
- Режим игры / состав партии / seed, если важно: атака охранником с пистолетом; переброс доступен от пистолета.

## Подготовка и шаги воспроизведения

1. Выполнить атаку охранником с пистолетом.
2. Запомнить значение кубика в окне атаки.
3. Нажать переброс пистолета пять раз в соответствующих атаках и сравнить значения до и после каждого переброса.

Частота воспроизведения: по сообщению пользователя; точная частота неизвестна.

## Результат

- **Фактический:** после переброса остаётся число, выпавшее при первом броске.
- **Ожидаемый:** значение переброшенного кубика обновляется на результат нового броска, и именно новый набор используется при фиксации проверки/атаки.
- **Основание ожидания:** сообщение пользователя; `docs/prompts-review-game-mechanics.md`, раздел 14, указывает, что результат первого броска не фиксируется до выбора переброса; `docs/effects-vocabulary.md` описывает повторный бросок для соответствующих эффектов.

## Влияние

- Что пользователь не может сделать или какое состояние портится: игрок не может получить либо увидеть результат разрешённого переброса; итог проверки может быть неверным.
- Масштаб / обходной путь: атаки охранника с пистолетом; сообщено о пяти перебросах подряд без изменения отображаемых чисел.
