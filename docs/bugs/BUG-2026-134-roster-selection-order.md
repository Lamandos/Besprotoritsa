# BUG-2026-134 — Очерёдность ходов не следует порядку выбора персонажей

## Суть

На экране формирования отряда нет номера очереди у выбранных героев. Порядок
партии формируется по каталогу персонажей, а пользователь просит определять его
порядком нажатий при выборе.

## Среда

- Версия приложения / commit: рабочая копия на 2026-11-09; точный commit не указан.
- Платформа и версия ОС / браузера: неизвестно.
- Устройство или размер окна, если важно: экран выбора персонажей.
- Режим игры / состав партии / seed, если важно: новая одиночная партия, 2–4 героя.

## Подготовка и шаги воспроизведения

1. Открыть выбор персонажей.
2. Выбрать героев в порядке, отличном от каталога.
3. Начать новую партию и посмотреть очерёдность героев.

Частота воспроизведения: всегда.

## Результат

- **Фактический:** номера хода не показаны; список партии сортируется по каталогу,
  а не по порядку нажатий.
- **Ожидаемый:** рамка каждого выбранного героя показывает зелёный номер 1–4;
  сформированный порядок ходов совпадает с порядком выбора.
- **Основание ожидания:** продуктовое решение пользователя от 2026-11-09;
  `docs/rules-spec.md`, «Подготовка» и «Структура раунда» требуют сохранить
  детерминированную очерёдность в партии.

## Влияние

- Что пользователь не может сделать или какое состояние портится: нельзя задать
  желаемую очерёдность ходов при выборе героев.
- Масштаб / обходной путь: все новые партии; обходной путь отсутствует.

## Доказательства

Описание пользователя от 2026-11-09; скриншоты выбора не приложены.
