# BUG-2026-017 — Кнопка движения содержит координаты выбранной клетки

## Суть

На кнопке движения выводятся координаты цели, хотя цель уже выбрана на поле. Пользователь просит убрать координаты из её текста.

## Среда

- Версия приложения / commit: версия партии пользователя неизвестна; код для первичного анализа — `5938b26` (`main` после PR #30).
- Платформа и версия ОС / браузера: неизвестно.
- Устройство или размер окна, если важно: неизвестно.
- Режим игры / состав партии / seed, если важно: неизвестно.

## Подготовка и шаги воспроизведения

1. В ход героя выбрать соседнюю открытую клетку, в которую можно переместиться.
2. Посмотреть подпись появившейся кнопки движения.

Частота воспроизведения: неизвестно; шаги составлены по сообщению и ещё не проверены на партии.

## Результат

- **Фактический:** Кнопка движения содержит координаты клетки.
- **Ожидаемый:** Подпись кнопки движения не содержит координат; действие по-прежнему относится к выбранному фрагменту поля.
- **Основание ожидания:** Явное требование пользователя к подписи; [правила, «Фаза игроков»](../rules-spec.md) определяют допустимость перемещения, но не требуют координат на кнопке.

## Влияние

- Что пользователь не может сделать или какое состояние портится: Подпись перегружена и занимает место, нужное для названия действия.
- Масштаб / обходной путь: Кнопки движения; обходной путь — игнорировать координаты.

## Доказательства

Источник — сообщение пользователя от 2026-10-08. Скриншот, лог и сохранение не приложены.

`AppStrings.moveCommand` формирует строку с `q, r`; `_availableTileCommands` передаёт её в кнопку, а `_WideCommandButton` добавляет её под «ДВИЖЕНИЕ».
