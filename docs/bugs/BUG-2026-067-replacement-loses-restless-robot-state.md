# BUG-2026-067 — Замена героя теряет истощение робота у Беспокойного

## Суть

После смерти героя истощённый робот переходит к Беспокойному, но при появлении
героя из резерва маркер остаётся только на заменяемом `PlayerState`. Позже
победитель получает робот готовым.

## Среда

- Версия приложения / commit: PR #33, commit `e6f38ba`.
- Платформа и версия ОС / браузера: rules-пакет.
- Устройство или размер окна, если важно: не важно.
- Режим игры / состав партии / seed, если важно: погибший герой выбран из резерва; Беспокойный переживает границу следующего хода.

## Подготовка и шаги воспроизведения

1. Истощить экипированного робота.
2. Погибнуть с роботом; выбрать героя из резерва.
3. Дождаться появления героя из резерва на следующей границе хода.
4. Уничтожить Беспокойного и проверить состояние полученного робота.

Частота воспроизведения: всегда.

## Результат

- **Фактический:** создание нового `PlayerState` не переносит `exhaustedRobots`; трофей передаётся готовым.
- **Ожидаемый:** состояние готовности хранится вместе с роботом у Беспокойного до передачи победителю.
- **Основание ожидания:** `docs/rules-spec.md`, раздел «Смерть персонажа и Беспокойный», передаёт снаряжение Беспокойному и затем победителю; раздел правил роботов сохраняет истощение до восстановления. `BUG-2026-049` фиксирует это поведение до замены героя.

## Влияние

- После обычной замены героя можно повторно применить активную способность робота без восстановления.
- Масштаб / обходной путь: Беспокойный с истощённым роботом доживает до появления героя из резерва.
