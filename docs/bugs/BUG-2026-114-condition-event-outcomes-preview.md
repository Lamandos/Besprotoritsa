# BUG-2026-114 — Условные исходы событий показаны как гарантированный успех

## Суть

Вариант события без проверки навыка, исход которого зависит от условия карты,
показывает успешный текст как безусловный результат и скрывает текст провала.
Например, отправить дроида за ящиком можно выбрать без робота, но игрок увидит
только награду, хотя при отсутствии робота исходом будет провал.

## Среда

- Версия приложения / commit: PR #36, `7f122aa`.
- Платформа и версия ОС / браузера: неизвестно; замечание автоматического ревью.
- Устройство или размер окна, если важно: экран события.
- Режим игры / состав партии / seed, если важно: ожидающий выбор опции события.

## Подготовка и шаги воспроизведения

1. Открыть событие `huge-crate`, оставив героя без робота.
2. Посмотреть вариант «Отправить дроида за ящиком».
3. Повторить для `nest-room`, когда у героя нет огнемёта, и варианта «Сжечь гнездо».

Частота воспроизведения: всегда для этих вариантов.

## Результат

- **Фактический:** интерфейс подписывает успешный исход как «Результат» и не
  показывает провал.
- **Ожидаемый:** до выбора показываются обе ветви с подписями «Успех» и «Провал»;
  интерфейс не обещает условную награду как гарантированную.
- **Основание ожидания:** замечание ревью PR #36; требование пользователя показывать
  исходы вариантов события; `docs/rules-spec.md`, раздел «Фаза событий» требует
  показывать варианты до выбора. В `content/events.json` оба варианта явно задают
  `autoOutcome: condition` и обе ветви текста.

## Влияние

- Что пользователь не может сделать или какое состояние портится: игрок выбирает
  событие, ожидая награду, которой условный исход не гарантирует.
- Масштаб / обходной путь: варианты `huge-crate` 2 и `nest-room` 1; вся информация
  об исходах доступна только после выбора.
