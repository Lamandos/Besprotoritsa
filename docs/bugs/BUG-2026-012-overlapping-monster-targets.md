# BUG-2026-012 — Нельзя выбрать перекрытого монстра в той же клетке

## Суть

Если несколько монстров находятся на одной клетке, их карточки рисуются поверх
друг друга. Карточка верхнего монстра перехватывает нажатия и лишает игрока
доступа к остальным монстрам и к их кнопкам атаки.

## Среда

- Версия приложения / commit: PR #29, `c335ca9`
- Платформа и версия ОС / браузера: Flutter widget test; платформа пользователя неизвестна
- Устройство или размер окна, если важно: игровое поле
- Режим игры / состав партии / seed, если важно: обычная партия, несколько монстров в одной клетке

## Подготовка и шаги воспроизведения

1. Поместить двух разных монстров в одну клетку.
2. Открыть экран игры.
3. Нажать карточку монстра, которая находится ниже в порядке отрисовки.

Частота воспроизведения: всегда при совпадающих границах карточек.

## Результат

- **Фактический:** нажатие по перекрытой карточке открывает карточку верхнего монстра; атаковать перекрытого монстра нельзя.
- **Ожидаемый:** игрок может открыть и выбрать каждого монстра на клетке, в том числе выполнить атаку по выбранному монстру.
- **Основание ожидания:** замечание Codex Review к PR #29; `docs/rules-spec.md`, раздел «Фаза игроков» задаёт атаку монстра в своей клетке, но не ограничивает выбор одной целью при совпадении жетонов.

## Влияние

- Игрок может быть лишён доступной цели атаки и застрять в бою, когда выбранный верхний монстр слишком силён.
- Масштаб / обходной путь: для перекрытой карточки обходного пути нет.

## Доказательства

Замечание review PR #29 (GitHub, путь `packages/besprotoritsa_app/lib/src/mvp/mvp_game_screen_part_3.dart`, строка 564); отдельного скриншота нет.

## Границы проверки

- Подозреваемая область кода: `_TokenLayer`, `_MonsterToken` в `mvp_game_screen_part_3.dart`.
- Релевантные существующие тесты / спецификации: `packages/besprotoritsa_app/test/mvp_screen_test.dart`; `docs/rules-spec.md`, «Фаза игроков» и «Бой, урон и состояния».
- Что пока неизвестно: фактическая частота совместного появления монстров в обычной партии.

## Регрессионный тест

- Тестовый файл и имя теста: `packages/besprotoritsa_app/test/mvp_screen_test.dart`, `co-located monster cards remain individually reachable`.
- Команда запуска: `cd packages/besprotoritsa_app && flutter test test/mvp_screen_test.dart --plain-name 'co-located monster cards remain individually reachable'`.
- **До исправления (красный):** `cd packages/besprotoritsa_app && flutter test test/mvp_screen_test.dart --plain-name 'co-located monster cards remain individually reachable'`.
- Результат и причина падения: тест завершается ошибкой assertion на проверке имени перекрытого монстра: ожидаемый текст `underlying-monster` отсутствует, потому что нажатие открывает карточку верхнего `top-monster`.
- **После исправления (зелёный):** `cd packages/besprotoritsa_app && flutter test test/mvp_screen_test.dart --plain-name 'co-located monster cards remain individually reachable'` — пройдено.
- Результат связанных проверок: `cd packages/besprotoritsa_app && flutter test test/mvp_screen_test.dart` — все 4 widget-теста пройдены.

## Исправление

- Изменённые файлы: `packages/besprotoritsa_app/lib/src/mvp/mvp_game_screen_part_3.dart`, `packages/besprotoritsa_app/test/mvp_screen_test.dart`.
- Краткое описание исправления: жетоны монстров в одной клетке раскладываются в сетку без перекрытия; центр каждой карточки доступен для нажатия.
- Остаточные ограничения или связанные баги: нет известных.
