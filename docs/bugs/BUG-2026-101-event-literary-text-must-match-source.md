# BUG-2026-101 — Литературные тексты событий должны совпадать с оригинальными картами

## Суть

При показе результата розыгрыша текст исхода отличается от исходника. Все
литературные разделы карт событий должны быть дословно перенесены из оригинала.

## Среда

- Версия приложения / commit: неизвестно.
- Платформа и версия ОС / браузера: браузерная версия; точные версии неизвестны.
- Устройство или размер окна, если важно: неизвестно.
- Режим игры / состав партии / seed, если важно: розыгрыш карты события.

## Подготовка и шаги воспроизведения

1. Разыграть карту события с исходом.
2. Сверить описание, варианты и литературные тексты успеха/провала с оригиналом.
3. Повторить сверку для остальных литературных разделов карт событий.

Частота воспроизведения: подтверждено владельцем проекта; полный список расхождений неизвестен.

## Результат

- **Фактический:** показанный текст исхода и другие текстовые разделы не во всех случаях совпадают дословно с источником.
- **Ожидаемый:** описание, названия вариантов, их литературные формулировки и тексты исходов точно передают оригинальную карту; игровые эффекты остаются отдельными от печатного текста.
- **Основание ожидания:** `materials/события.pdf` и сообщение владельца проекта от 2026-10-14.

## Влияние

- Что пользователь не может сделать или какое состояние портится: игрок читает изменённую историю/формулировки исходной карты.
- Масштаб / обходной путь: все карты событий; дословные тексты хранятся в отдельной транскрипции исходных карт.

## Доказательства

Исходный набор карт: `materials/события.pdf`. Связанный ранее закрытый BUG-2026-031 проверял только отдельные тексты карты `ship-map`; охват остальных карт не подтверждён.

## Границы проверки

- Подозреваемая область кода (если известна): `content/i18n/ru.json`, `content/events.json`, generated runtime content и экран результата события.
- Релевантные существующие тесты / спецификации: BUG-2026-020, BUG-2026-031; `docs/rules-spec.md`, раздел «Фаза событий»; `packages/besprotoritsa_app/test/reported_gameplay_bugs_test.dart`.
- Что пока неизвестно: структура отдельных литературных полей для машинных потребителей. Интерфейс выбора и результата использует соответствующий раздел из существующих локализованных полей, а полная транскрипция карты остаётся в `content/event_source_text_ru.json`.

## Регрессионный тест

- Тестовый файл и имена тестов: `packages/besprotoritsa_app/test/reported_gameplay_bugs_test.dart` — `BUG101 event result shows the verbatim source card text`, `BUG101 every event card has the exact source transcription`.
- Команда запуска: `cd packages/besprotoritsa_app && flutter test test/reported_gameplay_bugs_test.dart --name 'BUG101 event result shows the verbatim source card text' --reporter expanded`.
- **До исправления (красный):** `red_verified`, assertion failure.
- Результат и причина падения: результат розыгрыша не содержал полный текст `cabin-noise` из PDF; проверка не нашла ни одного соответствующего текста. Отдельный тест подтвердил, что локализованный исход был сокращён.
- **После исправления (зелёный):** команда выше и `flutter test test/reported_gameplay_bugs_test.dart --name 'BUG101' --reporter expanded` — все 3 теста прошли.
- Результат связанных проверок: `flutter test test/reported_gameplay_bugs_test.dart --reporter expanded` — все 53 теста прошли; `dart analyze` — ошибок и замечаний нет.

## Исправление

- Изменённые файлы: `content/event_source_text_ru.json`, `tool/generate_mvp_runtime.dart`, `packages/besprotoritsa_app/lib/src/game/full_game_state.dart`, `packages/besprotoritsa_app/lib/src/mvp/mvp_game_screen_part_4.dart`, `mvp_game_screen_part_5.dart`, `mvp_game_screen_part_7.dart`, `mvp_game_feedback.dart`, сгенерированный `full_runtime_content.g.dart`, тесты.
- Краткое описание исправления: добавлены транскрипции всех 88 карт из `materials/события.pdf`; генератор проверяет полное совпадение ID. Полная транскрипция сохранена в данных карты. В окне выбора и результате теперь выводятся соответствующие поля варианта; при результате показывается исход выбранной ветки, а последствия игры выводятся отдельно по состоянию.
- Остаточные ограничения или связанные баги: общий исходный текст остаётся одной транскрипцией на карту; экран розыгрыша разбирает структурированные поля событий и сохраняет их текст без изменений.
