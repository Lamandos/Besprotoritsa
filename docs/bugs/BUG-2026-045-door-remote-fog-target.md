# BUG-2026-045 — Пульт двери принимает координаты скрытых клеток

## Суть

Проверка пульта требует тип коридора, но не проверяет, что целевая клетка
открыта. В проекции мультиплеера закрытые клетки представлены заглушками
коридоров, а сервер валидирует настоящий скрытый тип.

## Среда

- Версия приложения / commit: PR #33, commit `80e07b4`.
- Платформа и версия ОС / браузера: мультиплеерный запуск rules-пакета.
- Устройство или размер окна, если важно: не важно.
- Режим игры / состав партии / seed, если важно: у персонажа есть `door-remote`, цель — закрытая координата.

## Подготовка и шаги воспроизведения

1. Иметь карту `door-remote` и достаточные действия и кредиты.
2. Отправить команду пульта для неоткрытой клетки.

Частота воспроизведения: всегда при отправке такой команды.

## Результат

- **Фактический:** сервер использует истинный тип скрытой клетки и принимает команду для закрытого коридора; ответ позволяет проверять тип скрытых координат.
- **Ожидаемый:** команда отклоняется, пока целевая клетка не открыта.
- **Основание ожидания:** координаты неоткрытых тайлов скрыты от игрока в `ProjectedGameStateCodec`; закрытые координаты не должны быть доступны для использования способности.

## Влияние

- Игрок может изменять нераскрытые клетки и получать информацию о скрытой карте через различие ответа сервера.
- Масштаб / обходной путь: пульт двери в мультиплеере.
