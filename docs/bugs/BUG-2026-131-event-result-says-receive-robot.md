# BUG-2026-131 — Текст результата говорит «возьмите робота»

## Суть

В результате события приложение предлагает «взять» робота из колоды, хотя робот автоматически выдан персонажу.

## Среда

- Версия приложения / commit: локальная рабочая копия; commit не зафиксирован в отчёте.
- Платформа и версия ОС / браузера: неизвестно.
- Устройство или размер окна, если важно: неизвестно.
- Режим игры / состав партии / seed, если важно: неизвестно.

## Подготовка и шаги воспроизведения

1. Успешно разыграть событие «Два ящика».

Частота воспроизведения: по сообщению пользователя; точная частота неизвестна.

## Результат

- **Фактический:** Текст: «Возьмите робота из колоды предметов».
- **Ожидаемый:** Заменить на «Получите робота», отражая автоматическую выдачу.
- **Основание ожидания:** Явное требование пользователя; цифровая реализация события уже выдаёт предмет автоматически.

## Влияние

- Что пользователь не может сделать или какое состояние портится: Текст подсказывает несуществующее действие игрока.
- Масштаб / обходной путь: сценарии, описанные выше; обходной путь неизвестен.
