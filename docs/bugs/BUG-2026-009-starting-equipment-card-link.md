# BUG-2026-009 — Для стартового имущества нужна ссылка на полную карту

## Суть

На экране выбора персонажей список стартового имущества показан на фоне
оформленной плашки и без перехода к полной карте предмета. По запросу владельца
проекта фон списка нужно убрать и добавить ссылку, открывающую полную карту
предмета.

## Среда

- Версия приложения / commit: неизвестно
- Платформа и версия ОС / браузера: неизвестно
- Устройство или размер окна, если важно: экран выбора персонажей; размер
  неизвестен
- Режим игры / состав партии / seed, если важно: выбор персонажа со стартовым
  имуществом

## Подготовка и шаги воспроизведения

1. Открыть экран выбора персонажей.
2. Найти персонажа со стартовым имуществом.
3. Посмотреть на строку «Стартовое имущество» и попытаться открыть полную карту
   предмета.

Частота воспроизведения: неизвестно.

## Результат

- **Фактический:** список стартового имущества находится на оформленном фоне;
  ссылка на полную карту предмета отсутствует.
- **Ожидаемый:** убрать фон у списка и добавить ссылку, открывающую полную карту
  каждого указанного предмета.
- **Основание ожидания:** требование пользователя от 2026-10-06.

## Влияние

- Что пользователь не может сделать или какое состояние портится: быстро
  прочитать полное описание стартового предмета со страницы выбора персонажей.
- Масштаб / обходной путь: относится к отображению стартового имущества;
  обходной путь не указан.

## Доказательства

Скриншот или запись экрана не предоставлены.

## Границы проверки

- Подозреваемая область кода (если известна): карточка персонажа в
  `packages/besprotoritsa_app/lib/src/menu/roster_selection_screen.dart`.
- Релевантные существующие тесты / спецификации: конкретные тесты и правило
  открытия полных карт не определены.
- Что пока неизвестно: нужно ли открывать карту нажатием на название предмета,
  отдельной кнопкой или иным элементом управления.

## Регрессионный тест

- Тестовый файл и имя теста: `packages/besprotoritsa_app/test/full_game_state_test.dart`, `roster starting item opens its full card scan`
- Команда запуска: `cd packages/besprotoritsa_app && flutter test test/full_game_state_test.dart --plain-name 'roster starting item opens its full card scan'`
- **До исправления (красный):** `flutter test test/full_game_state_test.dart --plain-name 'roster starting item opens its full card scan'` из `packages/besprotoritsa_app`.
- Результат и причина падения: assertion не нашёл элемент с ключом `starter-item-card-lucky-socks`; стартовое имущество было обычным текстом без действия.
- **После исправления (зелёный):** повторный запуск указанного теста прошёл; `Dialog` полной карты предмета появился.
- Результат связанных проверок: `flutter test test/full_game_state_test.dart test/responsive_layout_test.dart` из `packages/besprotoritsa_app` — 11 тестов прошли; целевые файлы без замечаний в `dart analyze`.

## Исправление

- Изменённые файлы: `packages/besprotoritsa_app/lib/src/menu/roster_selection_screen.dart`, `packages/besprotoritsa_app/test/full_game_state_test.dart`.
- Краткое описание исправления: стартовые предметы выведены отдельными текстовыми кнопками, каждая открывает скан карты.
