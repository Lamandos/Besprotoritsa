# BUG-2026-041 — При передаче робота теряется его состояние поворота

## Суть

При обмене использованным роботом передаётся карта, но маркер её истощения
остаётся у прежнего владельца. Получатель может применить уже использованную карту.

## Среда

- Версия приложения / commit: PR #33, commit `1fc7a92`.
- Платформа и версия ОС / браузера: любой запуск rules-пакета.
- Устройство или размер окна, если важно: не важно.
- Режим игры / состав партии / seed, если важно: робот использован в текущем раунде и затем передаётся другому игроку.

## Подготовка и шаги воспроизведения

1. Активировать экипированного робота, чтобы его карта повернулась и попала в `exhaustedRobots` владельца.
2. Передать карту робота другому игроку.
3. Попытаться использовать способность переданного робота.

Частота воспроизведения: всегда при передаче истощённого робота.

## Результат

- **Фактический:** карта у получателя не помечена истощённой и может сработать повторно; прежний владелец хранит устаревший маркер.
- **Ожидаемый:** состояние поворота следует за переданной картой, поэтому получатель не может повторно активировать её до готовности.
- **Основание ожидания:** `docs/effects-vocabulary.md`, `robot.exhaust` — поворот карты; `robot.ready` — возвращение робота в готовность. Передаётся физическая карта, включая её состояние.

## Влияние

- Обмен позволяет повторно применить способность робота, обходя правило истощения.
- Масштаб / обходной путь: обмены истощённых карт роботов.
