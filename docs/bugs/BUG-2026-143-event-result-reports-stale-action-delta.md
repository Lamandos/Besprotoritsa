# BUG-2026-143 — Результат события сообщает сброс уже применённого бонуса ОД

## Суть

Окно результата следующего события показывает `−1 ОД` для знахаря, хотя этот
штраф не относится к текущему событию, а ранее полученный бонус уже был применён
и число действий героя осталось увеличенным.

## Среда

- Версия приложения / commit: рабочая копия на 2026-11-09; точный commit не указан.
- Платформа и версия ОС / браузера: неизвестно.
- Устройство или размер окна, если важно: окно результата события.
- Режим игры / состав партии / seed, если важно: бонус `+1 ОД` на следующий ход,
  затем результат другого события.

## Подготовка и шаги воспроизведения

1. Событием дать знахарю `+1 ОД` на следующий ход.
2. Дождаться применения бонуса и разыграть следующее событие за другого героя.
3. Посмотреть перечисленные последствия второго события.

Частота воспроизведения: наблюдалось один раз; точная частота неизвестна.

## Результат

- **Фактический:** результат последующего события пишет «Знахарь — Следующий
  ход: −1 ОД», хотя `ОД` знахаря остаётся увеличенным на одно.
- **Ожидаемый:** событие сообщает только изменения, вызванные его выбором; уже
  применённый бонус действий не появляется как отрицательное последствие другого события.
- **Основание ожидания:** описание пользователя и состояние очков действий на
  скриншоте; `docs/rules-spec.md`, раздел «Фаза событий».

## Влияние

- Что пользователь не может сделать или какое состояние портится: журнал
  последствий противоречит фактическому состоянию и вводит в заблуждение.
- Масштаб / обходной путь: события после отложенных бонусов/штрафов действий.
