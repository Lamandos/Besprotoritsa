# BUG-2026-037 — Сетевая проекция не даёт купить предмет из терминала

## Суть

Состояние терминала в сетевой проекции содержит список предложенных карт, но не
содержит их локальные определения и данные карточек. Экран не может определить
стоимость, показывает неполные сведения и отключает покупку даже при наличии денег.

## Среда

- Версия приложения / commit: PR #33, commit `1fc7a92`.
- Платформа и версия ОС / браузера: сетевая игра; точная платформа неизвестна.
- Устройство или размер окна, если важно: неизвестно.
- Режим игры / состав партии / seed, если важно: multiplayer, активен выбор предмета терминала.

## Подготовка и шаги воспроизведения

1. Подключиться к сетевой партии и открыть терминал снабжения.
2. Иметь достаточно кредитов для одного из предложенных предметов.
3. Открыть предложение предмета.

Частота воспроизведения: всегда при неполной сетевой проекции.

## Результат

- **Фактический:** стоимость становится `0`, описание отсутствует, кнопка покупки отключена, потому что определение карты равно `null`.
- **Ожидаемый:** показать полную карточку из локального публичного каталога и разрешить нажатие, если кредитов хватает; при нехватке показать дефицит и отключить кнопку.
- **Основание ожидания:** требование BUG-2026-034 о полной информации перед покупкой; содержимое каталога является публичными данными, а выбор покупки проверяет сервер.

## Влияние

- Игрок не может купить предложение терминала в сетевой партии и не видит цену.
- Масштаб / обходной путь: затрагивает multiplayer-предложения терминалов.
