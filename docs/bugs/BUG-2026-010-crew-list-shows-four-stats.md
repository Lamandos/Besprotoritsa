# BUG-2026-010 — В списке экипажа видны только четыре характеристики

## Суть

На игровом экране в списке экипажа отображаются четыре характеристики персонажа
вместо пяти.

## Среда

- Версия приложения / commit: неизвестно
- Платформа и версия ОС / браузера: неизвестно
- Устройство или размер окна, если важно: игровой экран; размер неизвестен
- Режим игры / состав партии / seed, если важно: открыть список экипажа во время
  игры

## Подготовка и шаги воспроизведения

1. Начать игру и открыть игровой экран.
2. Открыть список экипажа.
3. Сравнить число показанных характеристик персонажа с ожидаемыми пятью.

Частота воспроизведения: неизвестно.

## Результат

- **Фактический:** в списке экипажа видны только четыре характеристики.
- **Ожидаемый:** в списке экипажа видны все пять характеристик персонажа.
- **Основание ожидания:** требование пользователя от 2026-10-06; состав пяти
  характеристик для этого списка требует сверки с интерфейсом и данными игры.

## Влияние

- Что пользователь не может сделать или какое состояние портится: просмотреть
  полный набор характеристик членов экипажа с игрового экрана.
- Масштаб / обходной путь: затрагивает отображение характеристик в списке
  экипажа; обходной путь не указан.

## Доказательства

Скриншот или запись экрана не предоставлены.

## Границы проверки

- Подозреваемая область кода (если известна): UI списка экипажа на игровом
  экране; конкретный файл неизвестен.
- Релевантные существующие тесты / спецификации: `docs/rules-spec.md` и тесты
  списка экипажа требуют уточнения для этого отображения.
- Что пока неизвестно: масштаб проявления на других размерах; по `docs/mvp_spec.md`, `combatStrength` — дублирующая контрактная копия силы, поэтому пять характеристик — сила, наука, ремонт, выносливость и ловкость.

## Регрессионный тест

- Тестовый файл и имя теста: `packages/besprotoritsa_app/test/responsive_layout_test.dart`, `desktop landscape exposes the three persistent game panels` (assertion на пятую характеристику)
- Команда запуска: `cd packages/besprotoritsa_app && flutter test test/responsive_layout_test.dart --plain-name 'desktop landscape exposes the three persistent game panels'`
- **До исправления (красный):** `flutter test test/responsive_layout_test.dart --plain-name 'desktop landscape exposes the three persistent game panels'` из `packages/besprotoritsa_app`.
- Результат и причина падения: assertion на `ЛОВ` упал: в экипаже не отображалась ловкость.
- **После исправления (зелёный):** повторный запуск указанного теста прошёл; панель показывает пять атрибутов, включая выносливость и ловкость.
- Результат связанных проверок: `flutter test test/full_game_state_test.dart test/responsive_layout_test.dart` из `packages/besprotoritsa_app` — 11 тестов прошли; целевые файлы без замечаний в `dart analyze`.

## Исправление

- Изменённые файлы: `packages/besprotoritsa_app/lib/src/mvp/mvp_game_screen_part_4.dart`, `packages/besprotoritsa_app/test/responsive_layout_test.dart`.
- Краткое описание исправления: отображать пять игровых характеристик; `combatStrength` исключён как контрактный дубль силы согласно `docs/mvp_spec.md`.
- Остаточные ограничения или связанные баги: не определены
