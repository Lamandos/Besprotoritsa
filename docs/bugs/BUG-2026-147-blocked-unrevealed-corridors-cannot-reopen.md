# BUG-2026-147 — После события нельзя открыть закрытый неразведанный коридор

## Суть

После события «Сигнал астероидной опасности» неразведанные коридоры остаются заблокированными, а интерфейс предлагает раскрыть такой коридор обычной командой. Проверка команды отклоняет её, поэтому экипаж не может открыть новые участки корабля.

## Среда

- Версия приложения / commit: сохранение партии, приложенное 2026-11-09; исходная версия приложения неизвестна.
- Платформа и версия ОС / браузера: неизвестно.
- Устройство или размер окна, если важно: неизвестно.
- Режим игры / состав партии / seed, если важно: сохранение после события; активный игрок `hero-1`, `round=4`, `actions_left=2`.

## Подготовка и шаги воспроизведения

1. Загрузить сохранение `/home/lamand/Рабочий стол/save`.
2. Активный учёный стоит на шлюзе `airlock-4` в координатах `(0, -2)`.
3. Выбрать соседний заблокированный коридор `corridor-8` в `(0, -3)` или `corridor-9` в `(-1, -2)`.
4. Попробовать открыть его.

Частота воспроизведения: на приложенном сохранении.

## Результат

- **Фактический:** Сохранение содержит запись `event-asteroid-corridors-closed`; закрытые коридоры имеют `is_blocked=true`. UI для закрытой неразведанной клетки строит `RevealTileCommand`, который отклоняется из-за `destination.isBlocked`; команда открытия заблокированного коридора не предлагается.
- **Ожидаемый:** Согласно `docs/rules-spec.md`, соседний закрытый коридор можно открыть за одно действие, включая коридоры, закрытые событием «Метеоритный поток».
- **Основание ожидания:** `docs/rules-spec.md`, «Фаза игроков»; состояние и журнал приложенного сохранения.

## Влияние

- Что пользователь не может сделать или какое состояние портится: нельзя открыть скрытый коридор после закрытия коридоров событием, что блокирует дальнейшее исследование части корабля.
- Масштаб / обходной путь: вручную продолжить исследование через уже открытые коридоры; надежный обходной путь неизвестен.

`/home/lamand/Рабочий стол/save`; скриншотов этого состояния нет. В журнале сохранения на событии записано `event-asteroid-corridors-closed`.
