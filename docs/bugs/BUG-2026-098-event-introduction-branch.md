# BUG-2026-098 — Вступление события скрыто, а обычный переброс получает действие карты

## Суть

Вступление события отрисовывается только для решений без `eventId`. Настоящее
решение события остаётся без вступления, а обычное решение переброса показывает
действие «Вся карта», которое ссылается на отсутствующий `eventId`.

## Среда

- Версия приложения / commit: PR #34, проверенный commit `14f190c`.
- Платформа и версия ОС / браузера: Flutter UI.
- Устройство или размер окна, если важно: не важно.
- Режим игры / состав партии / seed, если важно: окно выбора события и окно обычного переброса.

## Подготовка и шаги воспроизведения

1. Открыть решение события с `eventId`, например `cabin-noise`.
2. Убедиться, что вступление карты отображается перед вариантами выбора.
3. Запустить обычную проверку с доступным перебросом.
4. Убедиться, что в перебросе нет действия «Вся карта»; попытка открыть карту без `eventId` не должна падать.

Частота воспроизведения: всегда для соответствующего окна.

## Результат

- **Фактический:** ревью PR #34 подтверждает, что блок вступления расположен в ветке `eventId == null`; событие не получает вступление, а переброс получает карточное действие с `eventId!`.
- **Ожидаемый:** вступление и кнопка просмотра карты показываются только для решения события и до его вариантов; прочие решения не показывают событие.
- **Основание ожидания:** `docs/rules-spec.md`, раздел «Фаза событий», говорит, что описание и варианты видны до выбора; инлайн-ревью PR #34 от 2026-10-11.

## Влияние

- Описание карты события отсутствует перед выбором.
- Обычный переброс может аварийно завершиться при нажатии на «Вся карта».
- Масштаб / обходной путь: все решения событий и обычные перебросы скилл-чека.

## Доказательства

## Регрессионный тест

- Тестовый файл и имя тестов: `packages/besprotoritsa_app/test/reported_gameplay_bugs_test.dart` — `BUG098 event introduction appears for event choice`, `BUG098 generic reroll has no event card action`.
- Команда запуска: `cd packages/besprotoritsa_app && flutter test test/reported_gameplay_bugs_test.dart --plain-name 'BUG098'`.
- **До исправления (красный):** команда завершилась провалом assertion в обоих тестах: в `AlertDialog` не найден текст вступления; в обычном перебросе найдено две кнопки «Вся карта».
- Результат и причина падения: вступление и действие карточки находятся в ветке `eventId == null`, поэтому недоступны для решения события и ошибочно отображаются у generic переброса.

- Результат связанных проверок: `flutter test test/reported_gameplay_bugs_test.dart` — `00:04 +46: All tests passed!`; `./tool/run_checks.sh` — успешно, включая форматирование, анализ, контент-валидаторы и тесты пакетов.

## Исправление

- Изменённые файлы: `packages/besprotoritsa_app/lib/src/mvp/mvp_game_screen_part_5.dart`, `packages/besprotoritsa_app/test/reported_gameplay_bugs_test.dart`.
