# BUG-2026-138 — Торговый бот скрывает непокупаемые сейчас припасы из пяти предложений

## Суть

После ремонта торгового бота интерфейс показывает одну кнопку покупки, хотя
бот открывает пять карт припасов и разрешает покупать любое их количество.
Предложения, на которые временно не хватает кредитов, не видны как варианты.

## Среда

- Версия приложения / commit: рабочая копия на 2026-11-09; точный commit не указан.
- Платформа и версия ОС / браузера: неизвестно.
- Устройство или размер окна, если важно: окно выбора торгового бота.
- Режим игры / состав партии / seed, если важно: успешная проверка ремонта события `trade-bot`.

## Подготовка и шаги воспроизведения

1. Успешно починить торгового бота.
2. Иметь недостаточно кредитов для части предложенных карт.
3. Посмотреть список доступных предложений и попытаться купить несколько карт.

Частота воспроизведения: наблюдалось в приложенной партии; точная частота неизвестна.

## Результат

- **Фактический:** список показывает только доступную по текущему остатку кнопку
  покупки; остальные раскрытые карты с ценой не видны.
- **Ожидаемый:** все пять предложенных карт и их цены видны; непосильные покупки
  явно отключены; доступные покупки можно совершать последовательно до пяти раз.
- **Основание ожидания:** карта `trade-bot` в `materials/события.pdf` говорит
  открыть пять карт и купить любое их количество; `docs/rules-spec.md`, раздел
  «Зафиксированные цифровые решения для событий», разрешает до пяти покупок.

## Влияние

- Что пользователь не может сделать или какое состояние портится: нельзя
  сравнить все пять предложений и понять, какие из них недоступны по цене.
- Масштаб / обходной путь: успешная торговля у бота.
