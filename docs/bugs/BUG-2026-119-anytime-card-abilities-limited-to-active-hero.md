# BUG-2026-119 — Карты без ограничения по ходу заблокированы для неактивного героя

## Суть

Игрок не может применить способность своего героя, если сейчас ход другого героя,
даже когда текст карты не ограничивает применение своим ходом и не требует очков
действия. Сервер отклоняет команду до проверки карты, а редьюсер адресует способность
только `activePlayer`.

## Среда

- Версия приложения / commit: локальная `main`, `71d2119`.
- Платформа и версия ОС / браузера: сетевая игра; не зависит от браузера.
- Устройство или размер окна, если важно: не применимо.
- Режим игры / состав партии / seed, если важно: два героя в комнате; активен Ada,
  Boris владеет «Наноботами».

## Подготовка и шаги воспроизведения

1. Создать сетевую партию с героями Ada и Boris.
2. Во время хода Ada попытаться использовать «Наноботы» из рюкзака Boris.
3. Сверить отклонение команды с текстом карты и правилами времени применения.

Частота воспроизведения: всегда.

## Результат

- **Фактический:** сервер отклоняет команду Boris сообщением о том, что команды
  может отправлять только активный герой.
- **Ожидаемый:** карты без особого ограничения по времени применения, которые не
  тратят действие, можно применить в любой момент хода за их владельца. Карты с
  текстом «в свой ход», «в бою», проверкой или стоимостью действия остаются в своих
  временных окнах.
- **Основание ожидания:** `materials/правила игры.pdf`, стр. 17: карты с условием
  «В свой ход» применяются только на этапе действий этого игрока без траты очков;
  карты с условием «Потратить действие» дополнительно тратят очко действия; все
  остальные карты без дополнительных условий не требуют очков и применяются в любой
  момент хода. На «Наноботах» и PROT3-CT своего-ходового ограничения нет.

## Влияние

- Что пользователь не может сделать или какое состояние портится: команда не может
  применить свободный эффект, предусмотренный картой, пока ход другого героя.
- Масштаб / обходной путь: мультиплеер, только карты без ограничений по времени и
  стоимости действия; обходного пути нет.

## Доказательства

- `materials/правила игры.pdf`, раздел «Условия применения карт», стр. 17.
- Текущая проверка в `Room._handleCommand` в
  `packages/besprotoritsa_server/lib/src/room_manager.dart` отклоняет любой запрос
  от участника, чей герой не активен.

## Границы проверки

- Подозреваемая область кода: проверка активного героя в сервере, валидация и
  исполнение `UseCardAbilityCommand` в правилах, панель инвентаря.
- Релевантные существующие тесты / спецификации: `server_room_test.dart`,
  `active_card_abilities_test.dart`, исходные тексты карт в `content/i18n/ru.json`.
- Что пока неизвестно: другие способности с окном «в любой момент» будут учтены
  отдельно от карт «в свой ход», «в бою» и «немедленно».

## Исправление

- Изменённые файлы: `docs/rules-spec.md`, `packages/besprotoritsa_rules/lib/src/commands_reducer_part_1.dart`, `packages/besprotoritsa_rules/lib/src/commands_reducer_part_2.dart`, `packages/besprotoritsa_rules/lib/src/commands_reducer_part_11.dart`, `packages/besprotoritsa_server/lib/src/room_manager.dart`, `packages/besprotoritsa_app/lib/src/mvp/mvp_game_screen_part_4.dart`.
- Краткое описание исправления: добавлен серверно проверяемый владелец команды способности; другой живой герой может сыграть «Наноботы» или PROT3-CT без траты действия в любой момент хода, не прерывая ожидающее решение. Инвентарь выбранного героя показывает эти карты и применяет эффект к их владельцу; активный герой и его очки действий не меняются. Карты «в свой ход» и требующие действие остаются ограничены.
- Остаточные ограничения или связанные баги: для свободного применения разрешены только карты из текущего набора без ограничений по времени — «Наноботы» и PROT3-CT.
