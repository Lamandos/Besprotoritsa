# BUG-2026-071 — Интерфейс скрывает Воздушный баллон при одном действии

## Суть

Хотя правила разрешают переход между открытыми шлюзами по Воздушному баллону за
одно действие, интерфейс создаёт варианты использования только при двух и более.

## Среда

- Версия приложения / commit: PR #33, commit `44c9078`.
- Платформа и версия ОС / браузера: локальная и авторитетная многопользовательская игра.
- Устройство или размер окна, если важно: не важно.
- Режим игры / состав партии / seed, если важно: у героя в открытом шлюзе есть Воздушный баллон и осталось одно действие.

## Подготовка и шаги воспроизведения

1. Открыть шлюз, в котором находится герой, и другой открытый шлюз.
2. Оставить одно действие и положить Воздушный баллон в рюкзак.
3. Открыть инвентарь и попытаться выбрать переход к другому шлюзу.

Частота воспроизведения: всегда.

## Результат

- **Фактический:** список допустимых способностей пуст; кнопка использования недоступна.
- **Ожидаемый:** интерфейс предлагает переход; после выбора тратится одно действие.
- **Основание ожидания:** текст карты в `content/i18n/ru.json` и `content/i18n/en.json` указывает стоимость одного действия; `BUG-2026-064` закрепляет стоимость в rules-слое.

## Влияние

- Игрок теряет доступ к легальному переходу как последнему действию.
- Масштаб / обходной путь: иметь два действия перед использованием карты.
