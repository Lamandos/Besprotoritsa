# BUG-2026-126 — У шлюзов не показаны предметы и действия для перехода

## Суть

На карте не объясняется требование предмета для перехода между открытыми шлюзами, и нельзя выбрать конкретный доступный предмет для перехода.

## Среда

- Версия приложения / commit: локальная рабочая копия; commit не зафиксирован в отчёте.
- Платформа и версия ОС / браузера: неизвестно.
- Устройство или размер окна, если важно: неизвестно.
- Режим игры / состав партии / seed, если важно: неизвестно.

## Подготовка и шаги воспроизведения

1. Активный персонаж стоит на открытом шлюзе; выбрать другой открытый шлюз.

Частота воспроизведения: по сообщению пользователя; точная частота неизвестна.

## Результат

- **Фактический:** Нет подсказки по предметам и нет явных действий перехода для скафандра и/или баллона.
- **Ожидаемый:** Показать нужные предметы с цветом наличия у активного персонажа и предлагать отдельный переход к шлюзу для каждого доступного предмета.
- **Основание ожидания:** Явное требование пользователя; docs/rules-spec.md, § «Дискретная гекс-геометрия»: шлюзы соединяются дополнительным переходом со скафандром или баллоном.

## Влияние

- Что пользователь не может сделать или какое состояние портится: Игрок не может понять условия перехода или совершить его с поля.
- Масштаб / обходной путь: сценарии, описанные выше; обходной путь неизвестен.
