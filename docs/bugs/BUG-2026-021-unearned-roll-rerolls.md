# BUG-2026-021 — Переброс предлагается без понятного игрового источника

## Суть

Пользователь сообщает, что каждый бросок можно перебросить, хотя источник этого права не указан. Переброс должен предоставляться только действующим правилом, картой или эффектом.

## Среда

- Версия приложения / commit: версия партии пользователя неизвестна; код для первичного анализа — `5938b26` (`main` после PR #30).
- Платформа и версия ОС / браузера: неизвестно.
- Устройство или размер окна, если важно: неизвестно.
- Режим игры / состав партии / seed, если важно: неизвестно.

## Подготовка и шаги воспроизведения

1. Начать проверку героем без предметов или эффектов, дающих переброс для этой проверки.
2. Выполнить бросок и проверить доступность переброса.
3. Сравнить с разрешённым картой перебросом и его ограничениями.

Частота исходного сбоя у пользователя неизвестна. Регрессионный сценарий воспроизведён детерминированно, красный и зелёный результаты приведены ниже.

## Результат

- **Фактический:** По сообщению пользователя, переброс доступен после каждого броска без понятного основания.
- **Ожидаемый:** Без применимого источника переброс недоступен. Если источник есть, действуют предусмотренные им число перебросов, допустимые кубики и контекст; игроку понятно, откуда получена возможность.
- **Основание ожидания:** Явное требование пользователя; [правила, «Бой, урон и состояния»](../rules-spec.md) не устанавливают универсальный бесплатный переброс. В коде права переброса представлены конкретными эффектами (`pistol_attack_reroll`, `dice.reroll.twoPerAttack` и другими); ограничения сверяются с соответствующей картой.

## Влияние

- Что пользователь не может сделать или какое состояние портится: Лишние перебросы меняют вероятность успеха и результат игры.
- Масштаб / обходной путь: Проверки и броски, которым выдаётся переброс без применимого источника; утверждение о всех типах бросков ещё требует проверки.

## Доказательства

Источник — сообщение пользователя от 2026-10-08. Скриншот, лог и сохранение не приложены.

`_startRoll` в `commands_reducer_part_6.dart` безусловно задаёт `availableRerolls: 1`. Боевой `EffectEngine.resolveRoll` отдельно рассчитывает перебросы из hooks; это ещё не доказывает одинаковую проблему у всех бросков.

## Границы проверки

- Подозреваемая область кода (если известна): `packages/besprotoritsa_rules/lib/src/commands_reducer_part_6.dart` (`_startRoll`, `_resolveReroll`); `effect_engine.dart`, `effect_registry.dart`; UI решения в `packages/besprotoritsa_app/lib/src/mvp/mvp_game_screen_part_5.dart`.
- Релевантные существующие тесты / спецификации: `packages/besprotoritsa_rules/test/combat_colocation_test.dart`, `effects_engine_test.dart`, `commands_reducer_test.dart`; `packages/besprotoritsa_app/test/save_resume_scenario_test.dart`. [Спецификация правил](../rules-spec.md).
- Что пока неизвестно: Типы бросков и экипировка героя из сообщения. Необходимо отдельно проверить обычные, событийные, боевые проверки и уклонение, сохранив легальные перебросы.

## Исправление

- Изменённые файлы: `packages/besprotoritsa_rules/lib/src/commands_reducer_part_5.dart`, `commands_reducer_part_6.dart`; `packages/besprotoritsa_app/lib/src/mvp/mvp_game_screen_part_5.dart`; `packages/besprotoritsa_rules/test/commands_reducer_test.dart`; регрессии — `packages/besprotoritsa_app/test/reported_gameplay_bugs_test.dart`.
- Краткое описание исправления: Убран безусловный бесплатный переброс проверки. Право вычисляется из надетых карт с соответствующей областью навыков; в окне решения показано название источника. Боевые перебросы продолжают рассчитываться существующим EffectEngine.
- Остаточные ограничения или связанные баги: Проверены отсутствие права без источника, ремонтный переброс ключа, запрет того же переброса для науки и исчерпание лимита. Модель усталости роботов не изменялась; её отсутствие уже зафиксировано в спецификации. Проверки UI выполнены в локальной партии; отдельный сетевой UI-сценарий не воспроизводился, режим исходной партии неизвестен.
