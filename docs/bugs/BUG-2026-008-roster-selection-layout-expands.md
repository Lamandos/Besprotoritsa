# BUG-2026-008 — Экран выбора персонажей растягивается при разворачивании окна

## Суть

При разворачивании окна интерфейс выбора персонажей растягивается на всю
доступную ширину экрана. Компоновка перестаёт выглядеть фиксированной и
становится неудобной для выбора персонажей.

## Среда

- Версия приложения / commit: неизвестно
- Платформа и версия ОС / браузера: неизвестно
- Устройство или размер окна, если важно: окно до и после разворачивания; точные
  размеры неизвестны
- Режим игры / состав партии / seed, если важно: экран выбора персонажей перед
  началом игры

## Подготовка и шаги воспроизведения

1. Открыть экран выбора персонажей.
2. Развернуть окно приложения на весь экран.

Частота воспроизведения: неизвестно.

## Результат

- **Фактический:** интерфейс выбора персонажей растягивается на всю ширину
  экрана.
- **Ожидаемый:** при разворачивании окна экран выбора сохраняет компактную,
  ограниченную ширину компоновки.
- **Основание ожидания:** требование пользователя от 2026-10-06; точные целевые
  размеры и адаптивные правила не определены.

## Влияние

- Что пользователь не может сделать или какое состояние портится: выбирать
  персонажей в удобной компактной компоновке.
- Масштаб / обходной путь: неизвестно; обходной путь не указан.

## Доказательства

Скриншот или запись экрана не предоставлены.

- Релевантные существующие тесты / спецификации:
