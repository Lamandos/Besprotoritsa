# BUG-2026-029 — Лишняя кнопка выбора результата проверки

## Суть

В окне проверки навыка отображается «Оставить результат», даже когда ни одного законного переброса нет.

## Среда

- Версия приложения / commit: неизвестно.
- Платформа и версия ОС / браузера: неизвестно.
- Устройство или размер окна, если важно: нет.
- Режим игры / состав партии / seed, если важно: проверка без предметов/особенностей, дающих переброс.

## Подготовка и шаги воспроизведения

1. Выполнить проверку навыка героем без источников переброса.
2. Посмотреть действия в окне результата проверки.

Частота воспроизведения: по сообщению пользователя, всегда при отсутствии переброса.

## Результат

- **Фактический:** Пользователю предлагают «Оставить результат», хотя другого результата получить нельзя.
- **Ожидаемый:** Кнопка «Оставить результат» показывается только вместе с реальной доступной опцией переброса; иначе результат продолжается без фиктивного выбора.
- **Основание ожидания:** Явное требование пользователя; см. также закрытые решения о детерминированных проверках в `docs/rules-spec.md`, § «Бой, урон и состояния».

## Влияние

- Что пользователь не может сделать или какое состояние портится: лишнее действие создаёт впечатление, что результат можно изменить.
- Масштаб / обходной путь: проверки без доступных перебросов.

## Доказательства

Источник — сообщение пользователя от 2026-10-09. Скриншот не приложен.

## Границы проверки

- Подозреваемая область кода (если известна): `packages/besprotoritsa_app/lib/src/mvp/mvp_game_screen_part_5.dart` (`_decisionActions`).
- Релевантные существующие тесты / спецификации: тесты `BUG021` и `BUG024` в `packages/besprotoritsa_app/test/reported_gameplay_bugs_test.dart`.
- Что пока неизвестно: результат проверки должен автоматически зафиксироваться либо иметь нейтральную кнопку продолжения, если модель оставляет окно решения без переброса.
