# BUG-2026-007 — Плашка установки офлайн-версии не закрывается

## Суть

В веб-версии плашка с предложением установить офлайн-версию не закрывается и
перекрывает элементы интерфейса. Из-за этого продолжать работу с веб-версией
неудобно или невозможно в перекрытой области.

## Среда

- Версия приложения / commit: неизвестно
- Платформа и версия ОС / браузера: веб-версия; остальное неизвестно
- Устройство или размер окна, если важно: неизвестно
- Режим игры / состав партии / seed, если важно: неизвестно

## Подготовка и шаги воспроизведения

1. Открыть веб-версию приложения.
2. Дождаться плашки с предложением установить офлайн-версию.
3. Попытаться закрыть плашку и пользоваться перекрытой частью интерфейса.

Частота воспроизведения: неизвестно.

## Результат

- **Фактический:** плашка не закрывается и перекрывает интерфейс веб-версии.
- **Ожидаемый:** плашку можно закрыть; после закрытия она не мешает пользоваться
  веб-версией.
- **Основание ожидания:** требование пользователя от 2026-10-06.

## Влияние

- Что пользователь не может сделать или какое состояние портится: пользоваться
  элементами веб-интерфейса, которые перекрыты плашкой.
- Масштаб / обходной путь: масштаб неизвестен; обходной путь не указан.

## Доказательства

Скриншот или запись экрана не предоставлены.

## Границы проверки

- Подозреваемая область кода (если известна): веб-интерфейс предложения
  установить офлайн-версию; конкретный файл неизвестен.
- Релевантные существующие тесты / спецификации: неизвестно.
- Что пока неизвестно: браузер, размер окна, доступные действия закрытия и
  воспроизводимость проблемы на других браузерах.

## Регрессионный тест

- Тестовый файл и имя теста: `test/offline_install_banner.test.mjs` — закрытие баннера и сохранение закрытого состояния после нового статуса service worker.
- Команда запуска: `npm test` (из `packages/besprotoritsa_app/web`).
- **До исправления (красный):** `npm ci && npm test` — завершился с кодом 1.
- Результат и причина падения: assertion `the offline banner has a dismiss button` получил `actual: ~` (элемента нет); это подтверждает описанное отсутствие действия закрытия.
- **После исправления (зелёный):** `npm test` — 1 тест прошёл.
- Результат связанных проверок: тест использует jsdom для выполнения inline bootstrap-кода из `index.html`; `npm ci` завершился успешно.

## Исправление

- Изменённые файлы: `packages/besprotoritsa_app/web/index.html`, `packages/besprotoritsa_app/web/test/offline_install_banner.test.mjs`, `packages/besprotoritsa_app/web/package.json`, `packages/besprotoritsa_app/web/package-lock.json`, `.github/workflows/ci.yml`.
- Краткое описание исправления: добавлена доступная кнопка закрытия; закрытое состояние сохраняется при последующих статусах service worker и установочных событиях в течение текущей загрузки страницы. Добавлена jsdom-среда и запуск теста в CI.
- Остаточные ограничения или связанные баги: закрытие сбрасывается при перезагрузке страницы.
