# BUG-2026-006 — Арты заданий 28 и 29 смещены относительно исходного листа

## Суть

Генератор считает ячейки сюжетных заданий подряд, хотя на четвёртой странице исходного листа перед заданием 28 оставлена пустая ячейка.

## Среда

- Версия приложения / commit: PR #27, review on `f23ae8025b287e2c309388d05a6ed0c685c4b994`
- Платформа и версия ОС / браузера: любая
- Устройство или размер окна, если важно: не важно
- Режим игры / состав партии / seed, если важно: открыть арт задания 28 или 29

## Подготовка и шаги воспроизведения

1. Открыть сюжетное задание 28 или 29.
2. Нажать «Читать полностью».
3. Сравнить арт с `materials/задания сюжет.pdf`, страница 4.

Частота воспроизведения: всегда.

## Результат

- **Фактический:** арт задания 28 пустой, а арт задания 29 показывает печатное задание 28.
- **Ожидаемый:** задания 28 и 29 отображают соответствующие им ячейки исходного листа.
- **Основание ожидания:** номера и тексты карт на исходном PDF; задания 28 и 29 имеют собственные ID в `content/quests.json`.

## Влияние

- Что пользователь не может сделать или какое состояние портится: игрок не видит текст финальных сюжетных заданий в приложении.
- Масштаб / обходной путь: две финальные карты; обходного пути в UI нет.

## Доказательства

Последний review PR #27; исходник `materials/задания сюжет.pdf`, страница 4 показывает задания 28 и 29 во второй строке, во второй и третьей колонках.

## Границы проверки

- Подозреваемая область кода: quest mapping в `tool/extract_card_art.py`.
- Релевантные существующие тесты / спецификации: исходный PDF и артефакты `packages/besprotoritsa_app/assets/images/card-art/quest-quest-28.webp`, `quest-quest-29.webp`.
- Что пока неизвестно: нет.

## Регрессионный тест

- Тестовый файл и имя теста: `tool/test_extract_card_art.py`, quest art 28 and 29 use their printed source cells.
- Команда запуска: `python3 -m unittest tool.test_extract_card_art`.
- **До исправления (красный):** `python3 -m unittest tool.test_extract_card_art`.
- Результат и причина падения: оба subtest провалились при сравнении с ячейками источника: среднее pixel difference составило 51.02 для задания 28 и 34.46 для задания 29 (порог 8).
- **После исправления (зелёный):** `python3 -m unittest tool.test_extract_card_art` — прошёл; среднее расхождение обоих артов с соответствующими ячейками PDF ниже порога.
- Результат связанных проверок: `./tool/run_checks.sh` завершился с кодом 0; analyzer, content validation и все rule/app tests прошли.

## Исправление

- Изменённые файлы: `tool/extract_card_art.py`, `tool/test_extract_card_art.py`, `packages/besprotoritsa_app/assets/images/card-art/quest-quest-28.webp`, `quest-quest-29.webp`.
- Краткое описание исправления: сопоставить ID 28/29 реальным ячейкам второй строки листа и пересоздать арты.
- Остаточные ограничения или связанные баги: нет.
