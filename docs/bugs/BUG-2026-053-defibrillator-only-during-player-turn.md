# BUG-2026-053 — Дефибриллятор доступен при проверках события

## Суть

Дефибриллятор добавляется как источник переброса к проверкам навыка в фазе
событий, хотя его эффект разрешён только в ход игрока.

## Среда

- Версия приложения / commit: PR #33, commit `f45a6f2`.
- Платформа и версия ОС / браузера: rules package.
- Устройство или размер окна, если важно: не важно.
- Режим игры / состав партии / seed, если важно: у игрока есть дефибриллятор; он проходит проверку навыка события.

## Подготовка и шаги воспроизведения

1. Получить дефибриллятор.
2. Перейти в фазу событий и выбрать вариант с проверкой навыка.
3. Проверить доступные источники переброса.

Частота воспроизведения: всегда.

## Результат

- **Фактический:** дефибриллятор предлагается и может быть сброшен при проверке события.
- **Ожидаемый:** источник недоступен вне хода игрока; дефибриллятор остаётся у игрока.
- **Основание ожидания:** текст карты в `content/i18n/ru.json`: «Сбросьте в свой ход».

## Влияние

- Игрок может потратить дефибриллятор на эффект вне указанного картой временного окна.
- Масштаб / обходной путь: любая проверка навыка события при наличии карты.

## Доказательства

Новое замечание ревью PR #33: `discussion_r4235392468`.
