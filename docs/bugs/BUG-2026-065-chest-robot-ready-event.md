# BUG-2026-065 — Событие готовности роботов снимает истощение с робота в сундуке

## Суть

Если истощённого робота положили в общий сундук, событие `ready_robots` очищает
маркер, который хранит его состояние до получения карты другим игроком.

## Среда

- Версия приложения / commit: PR #33, commit `d8e6622`.
- Платформа и версия ОС / браузера: rules-пакет.
- Устройство или размер окна, если важно: не важно.
- Режим игры / состав партии / seed, если важно: два игрока; истощённый робот находится в общем сундуке во время события.

## Подготовка и шаги воспроизведения

1. Активировать робота и положить его в общий сундук, сохранив маркер истощения.
2. Применить событие `ready_robots`.
3. Забрать робота из сундука и экипировать.

Частота воспроизведения: всегда.

## Результат

- **Фактический:** глобальный сброс очищает маркер на игроке, хранящем состояние карты в сундуке; полученный робот снова готов.
- **Ожидаемый:** событие восстанавливает роботов игроков, но не меняет истощение робота, который всё ещё лежит в сундуке.
- **Основание ожидания:** `BUG-2026-046` фиксирует, что истощение является состоянием карты и должно следовать за роботом через общий сундук; `docs/rules-spec.md` описывает готовность события как восстановление роботов игроков.

## Влияние

- Робота можно повторно активировать после изъятия из сундука без Энергоблока.
- Масштаб / обходной путь: событие `ready_robots` во время хранения истощённого робота.
