# BUG-2026-046 — Через общий сундук робот теряет истощение

## Суть

Когда истощённый робот кладут в общий сундук, маркер остаётся у прежнего
владельца, а другой игрок получает карту без маркера и может активировать её.

## Среда

- Версия приложения / commit: PR #33, commit `f7fd2cf`.
- Платформа и версия ОС / браузера: любой запуск rules-пакета.
- Устройство или размер окна, если важно: не важно.
- Режим игры / состав партии / seed, если важно: два игрока, истощённый робот передан через общий сундук.

## Подготовка и шаги воспроизведения

1. Пометить робот игрока истощённым.
2. Положить карту робота в общий сундук.
3. Передать ход другому игроку и забрать карту из сундука.
4. Экипировать робота и попробовать применить его способность.

Частота воспроизведения: всегда.

## Результат

- **Фактический:** карта переходит к другому игроку без состояния истощения; прежний владелец сохраняет устаревший маркер.
- **Ожидаемый:** истощение следует за картой через общий сундук; получатель не может повторно активировать робота до восстановления.
- **Основание ожидания:** `docs/effects-vocabulary.md`, `robot.exhaust` и `robot.ready`; состояние поворота является состоянием карты и уже переносится при прямом обмене.

## Влияние

- Через общий сундук можно повторно активировать использованную способность робота.
- Масштаб / обходной путь: депонирование и получение истощённых роботов.
