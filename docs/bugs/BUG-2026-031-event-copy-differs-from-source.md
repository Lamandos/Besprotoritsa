# BUG-2026-031 — Текст события и текст результата не совпадают с картой

## Суть

Тексты описаний событий и текстов исхода в приложении расходятся с исходными картами.

## Среда

- Версия приложения / commit: неизвестно.
- Платформа и версия ОС / браузера: неизвестно.
- Устройство или размер окна, если важно: нет.
- Режим игры / состав партии / seed, если важно: событие `ship-map` отображено в приложенном скриншоте.

## Подготовка и шаги воспроизведения

1. Открыть событие в приложении.
2. Сверить название, описание, варианты и исходы с исходной картой в `materials/события.pdf`.
3. Проверить и записать каждое точное расхождение отдельно.

Частота воспроизведения: подтверждено для `ship-map`; список других карт пока неизвестен.

## Результат

- **Фактический:** Для `ship-map` локализация содержит сокращённые/переписанные описание и исходы. Например, описание говорит «Вы нашли карту корабля с незнакомым проходом», тогда как исходная карта сообщает: «Вы нашли карту корабля, которую никогда не видели до этого. На ней есть незнакомый вам проход.» Успех первой проверки тоже сокращён до «Вы находите проход и дроида».
- **Ожидаемый:** Игрок видит точную транскрипцию описания, действий и исходов исходной карты; технические последствия применяются отдельно и не подменяют текст карты.
- **Основание ожидания:** Явное сообщение пользователя; исходный источник — `materials/события.pdf`.

## Влияние

- Что пользователь не может сделать или какое состояние портится: игрок получает неверный текст правила/сюжета и может выбрать действие по искажённому описанию.
- Масштаб / обходной путь: список затронутых событий пока не установлен.

## Доказательства

Приложен скриншот окна `ship-map` (`/tmp/codex-clipboard-5186bb54-9a0d-461e-87e9-608e055f6306.png`). Эталон прочитан с карты на стр. 4 файла `materials/события.pdf`; JSON-локализация содержала отличия, приведённые выше.

## Границы проверки

- Подозреваемая область кода (если известна): `content/i18n/ru.json`, `content/events.json`, сборка runtime-контента и `packages/besprotoritsa_app/lib/src/mvp/mvp_game_feedback.dart`.
- Релевантные существующие тесты / спецификации: проверки схемы и контента; оригинал `materials/события.pdf`.
- Что пока неизвестно: пользователь не указал другие затронутые карты. Для описанного скриншота установлены и исправлены три отличающихся текста `ship-map`; остальные карты не включены в этот подтверждённый сценарий.

- Краткое описание исправления: Тексты описания и исходов `ship-map` восстановлены по исходной карте; regression test закрепляет полный текст.
