# BUG-2026-121 — Вариант события исполняется сразу после нажатия

## Суть

Карты событий с несколькими вариантами исполняют выбор сразу, поэтому перед разрешением нельзя ещё раз проверить выбранный вариант.

## Среда

- Версия приложения / commit: локальная рабочая копия; commit не зафиксирован в отчёте.
- Платформа и версия ОС / браузера: неизвестно.
- Устройство или размер окна, если важно: неизвестно.
- Режим игры / состав партии / seed, если важно: неизвестно.

## Подготовка и шаги воспроизведения

1. Открыть событие с несколькими вариантами; нажать один вариант.

Частота воспроизведения: по сообщению пользователя; точная частота неизвестна.

## Результат

- **Фактический:** Команда выбора сразу разрешается и может изменить состояние.
- **Ожидаемый:** Сначала отметить вариант, затем отдельной кнопкой подтвердить выбор; для события с одним вариантом подтверждение не требуется.
- **Основание ожидания:** Явное требование пользователя; правило событий в docs/rules-spec.md не задаёт отдельный экран подтверждения, поэтому это UX-решение владельца.

## Влияние

- Что пользователь не может сделать или какое состояние портится: Игроку трудно ознакомиться с выбранным действием до его применения.
- Масштаб / обходной путь: сценарии, описанные выше; обходной путь неизвестен.

## Исправление

- Изменённые файлы: `packages/besprotoritsa_app/lib/src/mvp/mvp_game_screen_part_5.dart`.
- Краткое описание исправления: Многовариантный выбор отмечается, для покупки на рынке показываются описание товара и цена, затем выбор применяется отдельной кнопкой «Подтвердить выбор».
- Остаточные ограничения или связанные баги: Подтверждение добавлено для обычных событий с несколькими вариантами; другие типы решений используют свои существующие подтверждения.
