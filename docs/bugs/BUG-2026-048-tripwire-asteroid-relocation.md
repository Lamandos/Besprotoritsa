# BUG-2026-048 — Перемещённый астероидом монстр не срабатывает на растяжку

## Суть

При вытеснении монстров событием «Метеоритный поток» разрешение совместного
размещения вызывается без ID прибывшего монстра, поэтому растяжка не убивает его.

## Среда

- Версия приложения / commit: PR #33, commit `f7fd2cf`.
- Платформа и версия ОС / браузера: любой запуск rules-пакета.
- Устройство или размер окна, если важно: не важно.
- Режим игры / состав партии / seed, если важно: не-босс перемещён из коридора в сектор с установленной растяжкой.

## Подготовка и шаги воспроизведения

1. Установить растяжку в соседнем открытом секторе.
2. Разместить не-босса в открытом коридоре.
3. Разрешить событие «Метеоритный поток», вытесняющее монстра в этот сектор.

Частота воспроизведения: всегда при перемещении монстра на клетку с растяжкой.

## Результат

- **Фактический:** монстр остаётся в секторе и может атаковать находящихся там персонажей; растяжка остаётся на поле.
- **Ожидаемый:** вошедший не-босс погибает от растяжки, которая затем отправляется в сброс.
- **Основание ожидания:** `docs/effects-vocabulary.md`, `monster.trapOnEnter` — убить не-босса, вошедшего или появившегося в секторе; `docs/rules-spec.md`, правило «Метеоритный поток» описывает перемещение существ.

## Влияние

- Монстр обходит ловушку при принудительном перемещении и может нанести лишний урон.
- Масштаб / обходной путь: вытеснение монстров из коридора событием «Метеоритный поток».
