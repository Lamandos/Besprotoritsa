# BUG-2026-022 — Текст кнопок действий отображается не полностью

## Суть

Подписи кнопок действий не помещаются целиком. Пользователь требует, чтобы название действия можно было полностью прочитать на самой кнопке.

## Среда

- Версия приложения / commit: версия партии пользователя неизвестна; код для первичного анализа — `5938b26` (`main` после PR #30).
- Платформа и версия ОС / браузера: неизвестно.
- Устройство или размер окна, если важно: неизвестно.
- Режим игры / состав партии / seed, если важно: неизвестно.

## Подготовка и шаги воспроизведения

1. Открыть игровую панель с доступными действиями.
2. Выбрать фрагмент поля или открыть решение с длинными подписями действий.
3. Проверить, полностью ли читаются подписи кнопок.

Частота воспроизведения: неизвестно; шаги составлены по сообщению и ещё не проверены на партии.

## Результат

- **Фактический:** Текст на кнопках действий обрезается или не вмещается полностью.
- **Ожидаемый:** Полная подпись каждого действия читается на кнопке в поддерживаемых размерах интерфейса; кнопка остаётся доступной для нажатия.
- **Основание ожидания:** Явное продуктовое требование пользователя; [правила](../rules-spec.md) не определяют размеры UI-кнопок.

## Влияние

- Что пользователь не может сделать или какое состояние портится: Невозможно уверенно определить действие по его подписи.
- Масштаб / обходной путь: Кнопки с длинными названиями; конкретный размер окна и обходной путь неизвестны.

## Доказательства

Источник — сообщение пользователя от 2026-10-08. Скриншот, лог и сохранение не приложены.

В `_WideCommandButton` ширина текста ограничена 98, используется `maxLines: 2` и `TextOverflow.ellipsis`; у завершения хода — одна строка. Какие именно подписи обрезались у пользователя, неизвестно.
