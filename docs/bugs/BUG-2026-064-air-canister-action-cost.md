# BUG-2026-064 — Воздушный баллон тратит лишнее действие

## Суть

Способность Воздушного баллона списывает два действия за переход между
шлюзами и не разрешает использовать карту, если осталось одно действие.

## Среда

- Версия приложения / commit: PR #33, commit `d8e6622`.
- Платформа и версия ОС / браузера: rules-пакет.
- Устройство или размер окна, если важно: не важно.
- Режим игры / состав партии / seed, если важно: ход игрока с Воздушным баллоном в рюкзаке.

## Подготовка и шаги воспроизведения

1. Оставить у игрока одно действие и Воздушный баллон.
2. Находясь в открытом шлюзе, применить карту для перехода в другой открытый шлюз.

Частота воспроизведения: всегда.

## Результат

- **Фактический:** способность отклоняется при одном оставшемся действии; при двух действиях переход тратит оба.
- **Ожидаемый:** карта сбрасывается и переход тратит одно действие.
- **Основание ожидания:** подтверждённый текст карты в `content/i18n/ru.json` и `content/i18n/en.json` говорит потратить одно действие; карта несёт `action.spend` в `content/supplies.json`. Стоимость обычного перемещения по шлюзу из `docs/rules-spec.md` не меняет стоимость отдельной способности карты.

## Влияние

- Игрок не может использовать допустимый переход как последнее действие и теряет лишнее действие при успешном переходе.
- Масштаб / обходной путь: переход между шлюзами картой Воздушный баллон.
