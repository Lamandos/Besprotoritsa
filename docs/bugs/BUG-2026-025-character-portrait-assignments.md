# BUG-2026-025 — Портреты персонажей перепутаны

## Суть

Пользователь сообщает, что в интерфейсе перепутаны пары портретов «Рабочий» / «Механик» и «Астронавт» / «Инженер».

## Среда

- Версия приложения / commit: неизвестно.
- Платформа и версия ОС / браузера: неизвестно.
- Устройство или размер окна, если важно: неизвестно.
- Режим игры / состав партии / seed, если важно: экран выбора персонажа и игровые панели.

## Подготовка и шаги воспроизведения

1. Открыть выбор персонажа либо панель экипажа.
2. Сверить портреты четырёх названных персонажей.

Частота воспроизведения: по сообщению пользователя, всегда.

## Результат

- **Фактический:** Изображения назначены не тем персонажам в двух указанных парах.
- **Ожидаемый:** Для каждого стабильного id персонажа показывается его собственный исходный портрет.
- **Основание ожидания:** Явное сообщение пользователя; стабильные id и локализованные имена находятся в `content/characters.json` и `content/i18n/ru.json`.

## Влияние

- Что пользователь не может сделать или какое состояние портится: игроки получают неверное визуальное представление о персонажах.
- Масштаб / обходной путь: все места, использующие общий `CharacterPortrait`.

## Доказательства

Источник — сообщение пользователя от 2026-10-09. Приложенный скриншот показывает экран события, а не портреты четырёх персонажей.
