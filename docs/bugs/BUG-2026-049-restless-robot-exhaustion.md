# BUG-2026-049 — Беспокойный возвращает истощённого робота готовым

## Суть

Если герой погибает с использованным роботом, карта робота переходит к
Беспокойному, но маркер истощения остаётся у погибшего. Победитель, получив
робота из трофеев, может сразу использовать способность повторно.

## Среда

- Версия приложения / commit: PR #33, commit `4e16677`.
- Платформа и версия ОС / браузера: любой запуск rules-пакета.
- Устройство или размер окна, если важно: не важно.
- Режим игры / состав партии / seed, если важно: два героя; у погибшего робот использован до смерти.

## Подготовка и шаги воспроизведения

1. Использовать экипированного робота, чтобы он стал истощённым.
2. Погибнуть с роботом в экипировке; робот переходит к Беспокойному.
3. Другой герой уничтожает Беспокойного и получает его снаряжение.
4. Проверить состояние полученного робота.

Частота воспроизведения: всегда.

## Результат

- **Фактический:** робот приходит в инвентарь победителя без маркера истощения.
- **Ожидаемый:** состояние истощения следует за картой через Беспокойного; получатель не может применить способность до восстановления.
- **Основание ожидания:** `docs/rules-spec.md`, раздел «Смерть персонажа и Беспокойный» передаёт экипировку Беспокойному и затем победителю; раздел правил роботов фиксирует поворот после использования до эффекта восстановления.

## Влияние

- Победитель может повторно активировать способность уже использованного робота.
- Масштаб / обходной путь: победа над Беспокойным с экипированным у погибшего роботом.
