# BUG-2026-054 — Пульт от дверей предлагает скрытые коридоры

## Суть

UI строит варианты применения пульта по всем коридорам, включая неоткрытые.
Если первый такой вариант скрыт, локальная проверка отключает кнопку даже при
наличии доступного открытого коридора; в сетевой игре скрытые варианты видны в
списке и отклоняются сервером.

## Среда

- Версия приложения / commit: PR #33, commit `f45a6f2`.
- Платформа и версия ОС / браузера: Flutter app.
- Устройство или размер окна, если важно: не важно.
- Режим игры / состав партии / seed, если важно: пульт в рюкзаке; первый свободный коридор скрыт, следующий открыт.

## Подготовка и шаги воспроизведения

1. Получить пульт от дверей и не менее 2 кредитов.
2. Оставить свободный скрытый коридор перед свободным открытым коридором в порядке поля.
3. Открыть инвентарь и посмотреть/нажать «Использовать» у пульта.

Частота воспроизведения: всегда при таком порядке клеток.

## Результат

- **Фактический:** кнопка может быть выключена из-за первого скрытого сектора; список целей содержит невалидные скрытые секторы.
- **Ожидаемый:** список целей содержит только открытые свободные коридоры, которые можно переключить.
- **Основание ожидания:** правило `door-remote` отклоняет fogged corridors в `BUG045`; UI должен предлагать только допустимые цели.

## Влияние

- Игрок может не использовать пульт, хотя допустимая цель существует, либо получает варианты, которые правила отклонят.
- Масштаб / обходной путь: изменить порядок поля или убрать скрытый коридор из начала списка.
