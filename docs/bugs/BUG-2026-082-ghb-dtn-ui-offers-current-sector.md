# BUG-2026-082 — UI GHB-DTN выбирает текущую клетку первой и отключает способность

## Суть

Локальный экран инвентаря включает текущую клетку выбранного героя в список
пунктов назначения GHB-DTN. Кнопка использования проверяет первую команду; если
это перемещение в ту же клетку, локальная валидация отключает кнопку, даже когда
есть другие разрешённые направления.

## Среда

- Версия приложения / commit: PR #33, commit `9dcba48`.
- Платформа и версия ОС / браузера: Flutter app, локальная игра.
- Устройство или размер окна, если важно: не важно.
- Режим игры / состав партии / seed, если важно: герой стоит в первой открытой
  клетке доски, у него экипирован готовый GHB-DTN, есть доступные клетки в
  пределах дальности.

## Подготовка и шаги воспроизведения

1. Экипировать готовый GHB-DTN и поставить героя в первую открытую клетку доски.
2. Открыть инвентарь, оставив достижимые открытые клетки в качестве пунктов
   назначения.
3. Проверить кнопку «Использовать».

Частота воспроизведения: всегда при таком порядке клеток.

## Результат

- **Фактический:** кнопка отключена, потому что первая сгенерированная команда
  указывает на текущую клетку; reducer отклоняет перемещение без смены клетки.
- **Ожидаемый:** текущая клетка исключена из пунктов назначения, а кнопка доступна
  при наличии хотя бы одной валидной цели.
- **Основание ожидания:** reducer отклоняет GHB-DTN команду без движения; выбор
  пункта назначения должен соответствовать доступным действиям.

## Влияние

- Игрок не может применить способность GHB-DTN через локальный инвентарь, хотя
  достижимая цель есть.
- Масштаб / обходной путь: переместить героя на другую клетку перед использованием.
