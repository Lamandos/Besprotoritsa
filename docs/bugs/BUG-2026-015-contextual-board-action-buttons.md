# BUG-2026-015 — Действия с фрагментом поля показываются только для выбранного фрагмента

## Суть

Кнопки перемещения, открытия и закрытия коридора сейчас появляются в общей панели независимо от выбранной клетки. Из-за этого цели одинаковых кнопок неочевидны.

## Среда

- Версия приложения / commit: `main` после PR #29
- Платформа и версия ОС / браузера: неизвестно
- Устройство или размер окна, если важно: интерфейс игры
- Режим игры / состав партии / seed, если важно: обычная партия

## Подготовка и шаги воспроизведения

1. Открыть ход персонажа на поле с доступными соседними фрагментами.
2. Не выбирать клетку либо выбрать конкретную клетку поля.
3. Проверить кнопки движения, открытия и закрытия коридора.

Частота воспроизведения: ожидаемо всегда.

## Результат

- **Фактический:** действия для разных клеток видны сразу и/или одновременно, без явной связи выбранной клетки с целевой командой.
- **Ожидаемый:** пока клетка не выбрана, кнопки движения, открытия и закрытия коридора скрыты. После выбора показываются только валидные действия, цель которых — выбранная клетка.
- **Основание ожидания:** явное продуктовое требование пользователя; условия допустимых действий сверяются с `docs/rules-spec.md`, раздел «Фаза игроков».

## Влияние

- Что пользователь не может сделать или какое состояние портится: пользователь не понимает, какую клетку затрагивает команда панели, и видит действия, не относящиеся к выбранной клетке.
- Масштаб / обходной путь: все ходы на карте; обходной путь — ориентироваться на координаты в отдельных кнопках.

## Доказательства

Скриншот не приложен.

## Границы проверки

- Подозреваемая область кода: `_availableCommands`, `_WideActionDock`, `_MobileActionDock`.
- Релевантные существующие тесты / спецификации: `packages/besprotoritsa_app/test/bug_2026_012_013_ui_test.dart`; `docs/rules-spec.md`, раздел «Фаза игроков».
- Что пока неизвестно: какие размеры экрана пользователь использует чаще; требование применимо к интерфейсу карты в обоих адаптивных режимах.

## Регрессионный тест

- Тестовый файл и имя теста: `packages/besprotoritsa_app/test/bug_2026_012_013_ui_test.dart` — `field action buttons appear only for a selected target and valid actions`.
- Команда запуска: `cd packages/besprotoritsa_app && flutter test test/bug_2026_012_013_ui_test.dart --plain-name 'field action buttons appear only for a selected target and valid actions'`.
- **До исправления (красный):** `red_verified`.
- Результат и причина падения: assertion находит «ОТКРЫТЬ КОРИДОР» до выбора фрагмента поля; дальнейшие проверки адресности действия не выполняются.
- **После исправления (зелёный):** `flutter test test/bug_2026_012_013_ui_test.dart` — все 6 тестов пройдены; кнопки действий скрыты до выбора клетки и после выбора ограничены допустимыми действиями.
- Результат связанных проверок: `flutter test test/mvp_screen_test.dart test/responsive_layout_test.dart` — пройдены; `dart analyze` изменённых UI и тестовых файлов — замечаний нет.

## Исправление

- Изменённые файлы: `packages/besprotoritsa_app/lib/src/mvp/mvp_game_screen_part_2.dart`, `mvp_game_screen_part_6.dart`, `mvp_game_screen_part_7.dart`, `packages/besprotoritsa_app/test/bug_2026_012_013_ui_test.dart`.
- Краткое описание исправления: выбор клетки хранится в компактном интерфейсе и передаётся в панели действий; настольная и мобильная панели показывают для неё только валидные команды движения, открытия или закрытия.
