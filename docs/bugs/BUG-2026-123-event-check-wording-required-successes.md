# BUG-2026-123 — Проверка события подписана как сложность

## Суть

Перед выбором события порог проверки показан термином «сложность», который не объясняет требуемый результат броска.

## Среда

- Версия приложения / commit: локальная рабочая копия; commit не зафиксирован в отчёте.
- Платформа и версия ОС / браузера: неизвестно.
- Устройство или размер окна, если важно: неизвестно.
- Режим игры / состав партии / seed, если важно: неизвестно.

## Подготовка и шаги воспроизведения

1. Открыть событие с проверкой навыка и посмотреть детали варианта.

Частота воспроизведения: по сообщению пользователя; точная частота неизвестна.

## Результат

- **Фактический:** Отображается «сложность N».
- **Ожидаемый:** Показывать количество требуемых успехов, например «Необходимо успехов: N», вместо «сложность».
- **Основание ожидания:** Явное требование пользователя; docs/rules-spec.md описывает проверки навыка, но не требует термина «сложность».

## Влияние

- Что пользователь не может сделать или какое состояние портится: Игрок может спутать порог успехов с отдельным параметром сложности.
- Масштаб / обходной путь: сценарии, описанные выше; обходной путь неизвестен.

Нет отдельного снимка; см. экран выбора события.
