# Словарь эффектов карт

Статус: **зафиксирован до реализации архитектуры эффектов**. Единственный
машиночитаемый источник этого словаря — `tool/inventory_effects.dart`; запуск
скрипта создаёт `content/effects_inventory.json`. Полный текстовый слой каждого
листа PDF сохраняется в `auditScope.sourceTextByPage`, а семантические карточки
ссылаются на словарь ниже. Идентификатор — контракт для будущих данных и
исполнителя, а не имя Dart-класса. Текст в первой колонке —
буквальная формулировка карты или точное нормализованное условие, если одна
формулировка повторяется на нескольких картах.

## Триггеры жизненного цикла

| Глагол/условие карты | `behaviorId` | Примеры карт-источников |
| --- | --- | --- |
| бросок пула до подсчёта успехов | `onRoll` | Циркулярная пила; Шлем стрелка |
| подсчитаны попадания, до разрешения урона | `onHit` | Экзо-перчатки; «Последний шанс» |
| цель вот-вот получит урон | `onDamageTaken` | PROT3-CT; Протонный щит |
| монстр убит | `onKill` | Лазерный резак; Ультразвуковой молот |
| начало раунда монстров / начало его хода | `onRoundStart` | Леший; Гнездо |
| перемещение, принудительное перемещение, вход или появление | `onMove` | Растяжка; Дробовик; Гнездо |
| игрок и Нарыв оказались в одном секторе | `onColocation` | Нарыв |
| существо умирает | `onDeath` | Чумной |

`onRoundStart` — имя границы раунда в движке; текст Лешего буквально говорит
«перед ходом», а текст Гнезда заменяет обычную атаку. Эти случаи должны
разрешаться в стадии монстра, а не как произвольные эффекты карты.
