# Контракт первой поставки 0.1.0

Этот документ задаёт поддерживаемую конфигурацию первой офлайн-поставки. Проверочная [матрица сборок](../platform-matrix.md) фиксирует, что удаётся собрать; она сама по себе не расширяет список поставляемых платформ.

## Платформы и артефакты

| Поставка | Минимальная версия | Архитектура и разрядность | Формат первой поставки |
| --- | --- | --- | --- |
| Web | Chrome 153 или новее — минимальная явно зафиксированная проверенная версия на дату контракта. Для других браузерных движков версия поддержки пока не заявлена. ОС определяется тем, на которой работает поддерживаемый Chrome. | Браузер выбирает WASM или JS fallback и нативную архитектуру; отдельных 32/64-битных Web-пакетов нет. | Статический каталог `build/web` по HTTPS; его можно установить как PWA. |
| macOS | macOS 12.0 или новее | Универсальное приложение: `arm64` и `x86_64` (64-бит). | `Besprotoritsa.app`; для передачи — ZIP-архив с `.app`. Для публичного выпуска требуется Developer ID-подпись и notarization. |
| Android | Android 5.0, API 21 или новее | APK/AAB содержит `armeabi-v7a` (32-бит), `arm64-v8a` (64-бит) и `x86_64` (64-бит). | APK для прямой установки; AAB для публикации через магазин. |

Первая поставка не поддерживает iOS, Windows и Linux. Сборка Linux, отмеченная как успешная в матрице, является технической проверкой, а не обязательством поставлять Linux-версию в 0.1.0.

## Размер окна и экрана

Минимальный целевой видимый экран игры — **360 × 560 логических пикселей** после вычета системных панелей. На меньшей области выпуск не считается поддерживаемым; меню может прокручиваться, но это не меняет минимальный порог. Для широкого трёхпанельного игрового вида нужно не менее **840 логических пикселей по ширине** в альбомной ориентации; ниже игра переключается на компактную раскладку. На телефоне поддерживается компактный портретный вид.

## Язык

В первой поставке язык интерфейса — **русский**. Хотя в репозитории есть английские переводы части игрового каталога, английский интерфейс в приложении не включён и не заявляется.

## Сохранения и совместимость

- Сохранения хранятся локально на устройстве/в браузере; облачной синхронизации между Web, Android и macOS нет.
- Web использует IndexedDB базы `besprotoritsa`, хранилище `game_saves`, в пределах origin сайта. На первом чтении переносит прежние записи из `localStorage` в IndexedDB; старая запись остаётся на месте.
- macOS и Android хранят файлы в приватном каталоге Application Support приложения. Обновление приложения сохраняет эти файлы; перенос на другой профиль, устройство или платформу не обещается.
- У сохранений нет срока истечения, и обновление приложения их не удаляет. Очистка данных сайта/профиля браузера, удаление приложения на Android или потеря устройства/профиля может привести к потере локальных сохранений; они не являются резервной копией.
- Текущая версия документа сохранения — `schema_version: 1`. Версия 0 (включая старое поле `schemaVersion` или отсутствие поля версии) мигрируется на чтении к версии 1. На нативных платформах результат сохраняется в новой версии при следующем сохранении партии; в Web старая localStorage-запись дополнительно копируется в IndexedDB при чтении.
- Будущие изменения формата получают следующую последовательную версию с явной миграцией. Неизвестная/отсутствующая миграция и версия новее клиента завершаются ошибкой загрузки; исходное сохранение автоматически не удаляется и не перезаписывается неудачной миграцией.

## Что значит «офлайн» для Web

«Офлайн» означает повторный запуск уже установленного PWA **или** запуск сайта после первого успешного посещения по HTTPS, когда service worker активировался и закэшировал приложение, runtime и все текущие игровые иллюстрации. Первый визит на сайт без сети не гарантируется: загрузить PWA и её ресурсы при первом обращении без соединения невозможно.
