## Контрольные суммы

SHA-256 ключевых файлов всех собранных дистрибутивов приведены в [offline-0.1.0.sha256](offline-0.1.0.sha256). Проверка из корня репозитория:

```sh
shasum -a 256 -c docs/releases/offline-0.1.0.sha256
```

Для целостности macOS-пакета дополнительно выполните:

```sh
codesign --verify --deep --strict \
  packages/besprotoritsa_app/build/macos/Build/Products/Release/Besprotoritsa.app
```

## Запуск для пользователей

- **Web.** Разместите *содержимое* `build/web` на HTTP(S)-хостинге. Откройте сайт один раз при подключённом интернете и дождитесь активации service worker; после этого игра и её ресурсы открываются офлайн. Для SKWasm-сборки хостинг должен отдавать `.wasm` как `application/wasm` и заголовок `Cross-Origin-Opener-Policy: same-origin`.
- **macOS.** Скопируйте `Besprotoritsa.app` в `/Applications` или другую пользовательскую папку и откройте его через Finder. Эта сборка ad-hoc-подписана для локальной проверки; при внешнем распространении Gatekeeper может запросить явное разрешение на первый запуск.
- **Android.** На устройстве разрешите установку из источника, через который получен файл, затем откройте `app-release.apk`. Сверьте SHA-256 перед установкой. Файл `.aab` предназначен для публикации через магазин, а не для прямой установки на устройство.
