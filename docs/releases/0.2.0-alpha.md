# Беспроторица 0.2.0-alpha

Статус: **alpha-кандидат; публичная поставка пока не принята**.

Версия приложения в этом PR — `0.2.0-alpha+1`. Предполагаемый Git-тег после
слияния и закрытия релизных gate — `v0.2.0-alpha`. Этот документ готовит
кандидат к выпуску; он не означает, что платформенные и правовые проверки
пройдены.

## Изменения кандидата

- Карточные иллюстрации подключены к игровым картам; карточки предметов,
  событий, заданий и монстров отображают информацию в сгруппированном виде.
- Фишки монстров используют полный прозрачный арт; открытие фишки показывает
  игровую карточку монстра. В окне разыгрываемого события показывается портрет
  персонажа, которому оно адресовано.
- Исправлено чтение инвентаря текущей партии. Заголовок инвентаря показывает
  портрет владельца.
- Обмен поддерживает выбор нескольких карт из рюкзака и экипировки с обеих
  сторон, а также передачу кредитов. Сетевые команды передают точные области
  инвентаря выбранных карт.
- Общий сундук можно открыть для просмотра в любой момент. У стартового отсека
  карты можно положить и взять одним действием.
- Активные события остаются в правой панели, пока они не сброшены; закладки
  переключают карточки.

## Проверки этого кандидата

| Проверка | Результат |
| --- | --- |
| `dart analyze` по изменённым UI, правилам, сетевому контроллеру и серверному парсеру | Пройдено без замечаний 2026-10-03 |
| `flutter build linux --debug` | Пройдено 2026-10-03; приложение запущено |
| `git diff --check` | Пройдено |
| Автоматические тесты и CI PR | Не запускались локально; результат CI ожидается в PR |

Эти результаты подтверждают только перечисленные проверки и не являются
приёмкой релизных артефактов.

## Оставшиеся release gates

- Пройти CI PR, включая тесты правил, приложения и контента.
- Пересобрать release-вариант для заявляемых платформ из commit кандидата.
  Ветка 0.2-alpha пока не подтверждает актуальную release-сборку Web, Android,
  macOS, Windows или Linux.
- Повторить ручную приёмку интерфейса, поля, событий и сохранений на целевых
  системах. Последний репозиторный чеклист 0.1.0 отмечает приёмку незавершённой;
  результаты старой сборки не засчитываются для этого кандидата.
- Подтвердить права на цифровое распространение исходных иллюстраций,
  извлечённых из PDF. В `asset-rights-0.1.0.md` уже зафиксированы неподтверждённые
  права для карточной графики; добавление артов не закрывает этот вопрос.
- После прохождения gates собрать контрольные суммы артефактов, обновить
  матрицу платформ и только затем создать Git-тег и GitHub prerelease.

Подробная исходная матрица и проверочные критерии остаются в
[`qa-checklist-0.1.0.md`](qa-checklist-0.1.0.md),
[`platform-matrix.md`](../platform-matrix.md) и
[`release-contract-0.1.0.md`](release-contract-0.1.0.md). Их открытые пункты
переносятся в alpha-приёмку до повторной проверки.
